# Notepatra v0.1.44 — Project Search UX + language-aware comment toggling

**Released**: 2026-05-07

Three Notepad++-style quality-of-life upgrades the editor was missing.

## Project Search

- **Red ✕ close button on the search panel** — far right of the title row,
  theme-independent (Windows close-button red `#E81123` at rest, white-on-red
  on hover). Click → the panel's tab goes away. Pre-v0.1.44 there was no
  way to dismiss the panel except by right-clicking the tab.
- **Stackable, collapsible search history** — pressing Search no longer
  wipes the previous results. Each search becomes a top-level session row
  with the query, flags, folder, hit count, and timestamp:

  ```
  🔎  "pwd"  Aa W — 5 hits in 1 file · 12:34:07 · /path/to/folder
       /path/to/folder/foo.py
            10:1   $pwd1 = Read-Host …
            11:1   $pwd2 = Read-Host …
       …
  ```

  Files are children; matches are grandchildren. Earlier sessions
  auto-collapse so the new one stands out. Capped at 10; oldest pruned.
- **Clear history** button wipes every stacked session in one click.

## Editor

- **Right-click `Toggle Line Comment` + `Toggle Block Comment`** —
  available only when the file's language is recognised. Pre-v0.1.44 the
  editor would prepend `#` regardless of file type, which silently turned
  Markdown lines into headings. Now: HTML/XML/Markdown use `<!-- -->`,
  PowerShell uses `<# #>`, SQL uses `--` line + `/* */` block, Python uses
  `#`, C-family uses `// ` line + `/* */` block, etc. — all routed through
  one canonical map.
- **Notepad++ shortcuts** — `Ctrl+Q` for line comment (alongside the
  existing `Ctrl+/`), `Ctrl+Shift+Q` for block comment.
- **Languages with line-comment support** (`#` or `//` or `--` or `;` or
  `%` or `!` or `REM `): Python, Bash, YAML, Ruby, Perl, PowerShell, TCL,
  CMake, Makefile, Properties, C/C++, C#, Java, JS, TS, D, Rust, Go,
  Swift, Kotlin, Verilog, POV, SQL, VHDL, Lua, ASM/NASM/MASM, IDL, Spice,
  PostScript, TeX, Matlab, Octave, Fortran, CoffeeScript, Batch.
- **Languages with block-comment support**: C-family + CSS + Pascal
  (`/* */`), HTML/XML/Markdown (`<!-- -->`), PowerShell (`<# #>`), Lua
  (`--[[ ]]`), Matlab/Octave (`%{ %}`), CoffeeScript (`### ###`), Ruby
  (`=begin =end`).

Languages without a known syntax (Plain Text, unrecognised extensions,
binary formats like Diff / IntelHex) get the menu items disabled with
the label `Toggle Line Comment (no syntax for Plain Text)` so the user
can see why nothing happens.

## Tests

`test_options_actually_work` — 25 new assertions covering the language
map for Python, JS, C++, SQL, Lua, HTML, Markdown, PowerShell, Bash,
Batch, Plain Text, and an unknown language. Catches any regression that
silently breaks comment toggling for a specific lexer.

## Files changed

- `src/editor.{h,cpp}` — new `CommentSyntax` struct + `commentSyntaxFor()`
  static helper, `toggleBlockComment()` method, `contextMenuEvent()`
  override.
- `src/projectsearch.{h,cpp}` — new `closeRequested` signal,
  `m_currentSession` pointer, `m_sessions` history list,
  `m_perSessionFiles` per-session file-row index. Title-row layout
  with the red ✕ close button. New "Clear history" button.
- `src/mainwindow.cpp` — wires `ProjectSearch::closeRequested` to tab
  removal; binds `Ctrl+Q` and `Ctrl+Shift+Q` in the Comment/Uncomment
  submenu; adds the new Toggle Block Comment action.
- `test_options_actually_work.cpp` — language-map asserts.
- `CMakeLists.txt` — `0.1.43 → 0.1.44`.
