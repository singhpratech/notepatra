# Notepatra v0.1.4 — Windows installer + 3-platform download counter

You wanted Notepatra to show up in **Settings → Apps → Installed apps** so you could uninstall it the normal way. v0.1.0 through v0.1.3 only shipped a portable zip, which doesn't write any registry entries, so Windows had no idea Notepatra was installed and Control Panel couldn't see it. Fixed.

## Added

### 🪟 Proper Windows installer — `notepatra-setup-0.1.4.exe`

NSIS MUI2 installer that does what every Windows app should do:

| Feature | What you get |
|---|---|
| **Registers in "Installed apps"** | `HKCU\Software\Microsoft\Windows\CurrentVersion\Uninstall\Notepatra` with `DisplayName`, `DisplayVersion`, `Publisher`, `InstallLocation`, `DisplayIcon`, `EstimatedSize`, `URLInfoAbout`, `HelpLink`, `NoModify`, `NoRepair` |
| **Generates uninstall.exe** | Removes files, registry entries, PATH, and shortcuts cleanly |
| **No UAC prompt** | Installs to `%LOCALAPPDATA%\Notepatra` per-user (admins can override the directory) |
| **Start Menu shortcut** | Under "Notepatra" folder with the embedded .ico |
| **Desktop shortcut** | Optional checkbox during install |
| **PATH integration** | Optional checkbox — adds the install dir to user PATH so `notepatra` works from any terminal |
| **Cosign signed + SLSA attested** | Same supply-chain verification as the zip |

The portable `.zip` is still on the release page for users who want it (USB drives, restricted environments, "I don't want anything in my registry").

### 🪟 `install.ps1` (PowerShell one-liner) also writes the Uninstall registry

If you install via `irm https://notepatra.org/install.ps1 | iex`, you now also get the "Installed apps" entry without having to download the .exe installer. The script writes the same registry keys and drops an `uninstall.ps1` next to the binary.

### 📊 Live 3-platform download counter on the website footer

The bottom of [notepatra.org](https://notepatra.org) now shows real-time download counts pulled directly from the GitHub Releases API, broken down by platform:

```
🐧 Linux        🍎 macOS       🪟 Windows
   42              17             89
```

Sums every binary across every release (excluding `.sig`/`.pem` signature siblings). Refreshes on every page load. Falls back to "—" if you're offline or rate-limited.

### 🛠 `scripts/bump_version.sh` — single-command release bump

New helper that updates **every** version reference in one shot — `docs/index.html` JSON-LD + hero badge + download label, `README.md` latest-release link + version table top row, `CHANGELOG.md` new section header, `release_notes/<tag>.md` blank stub. So we never ship another release where the README still says v0.1.0 while the binaries are at v0.1.4.

## Fixed

- 🔗 Stale `v0.1.0` references on the website homepage (JSON-LD `softwareVersion`, hero badge, SHA256SUMS link) bumped to current version.
- 🔗 README.md was still pointing to v0.1.0 in the "Latest release" link, the version-history table, and the SHA256SUMS download URL — now uses `releases/latest` everywhere or has been bumped.

## Verifying this release

Same as previous releases:
- SHA-256 checksums in `SHA256SUMS`
- Cosign keyless signatures in `*.sig` + `*.pem` (Sigstore + Rekor transparency log)
- SLSA build provenance attestation cryptographically linking each binary to this commit

The new `notepatra-setup-0.1.4.exe` is included in `SHA256SUMS` and has its own `.sig`/`.pem` cosign artifacts. See `SECURITY.md` for verification one-liners.
