# Notepatra v0.1.15 — 2026-04-20

Quality-of-life polish on top of v0.1.14. Theme-aware panels everywhere · AI Assistant upgraded with Coding Mode + Backend picker (OpenRouter in one click) · colourful ANSI terminal · modern REST client · real screenshots on the website.

## Highlights

### 🤖 AI Assistant — Coding Mode + Backend picker
- New **Coding Mode** toggle. ON = AI returns clean code only (no prose, no markdown fences, preserved indentation). Replace Selection drops it straight into the editor, Cursor-style.
- New **Backend** dropdown in the top bar — seven one-click presets:
  - Ollama · llama.cpp (GGUF) · OpenRouter (cloud) · LM Studio · Jan · OpenAI · Custom
- Selecting a backend auto-fills the URL and refreshes the model list. OpenRouter is now a two-click switch instead of buried in Settings.
- Fully theme-aware — Light (Clay palette) or Dark (VS Code-like greys).

### 🖥️ Terminal — ANSI colour + zsh prompt
- Proper ANSI SGR parser turns `\033[32m` escape codes into coloured text. `ls`, `grep`, `git`, `cargo`, `npm` — all render in colour.
- Auto-detects `$SHELL` env var. macOS users get zsh, fish users get fish, Windows users get pwsh if installed. Banner shows which shell is running.
- Injects `CLICOLOR=1`, `FORCE_COLOR=1`, `TERM=xterm-256color` so tools emit colours even when piped.
- Zsh-style prompt: Clay-orange directory name + teal ❯ inside a rounded pill.

### 🌐 REST Client — modern Postman / Thunder-Client layout
- Method dropdown · URL input · Send button across the top.
- Headers / Body tabs below.
- Colour-coded status badge: 2xx green, 3xx blue, 4xx amber, 5xx red — shows `200 OK · 43 ms · 1.2 KB`.
- Pretty-prints JSON response body.

### 💾 Git panel — VS Code SOURCE CONTROL chrome
- Branch pill at top, commit-message box, big green Commit button, Ctrl+Enter commits.
- 17 old action buttons hidden behind a `↻ ↓ ↑ ⋯` toolbar with `⋯ More` dropdown containing Clone / Init / Stage / Unstage / Discard / Checkout / Merge / Stash / etc.

### 🎨 Theme-aware everywhere
Every panel now reads `Config::theme` and swaps between Light (Clay palette) and Dark (VS Code greys):
- AI Assistant chat + bubbles + code blocks
- Search Results tree
- Markdown Preview (body + headings + code blocks + tables + blockquotes)
- Hex Editor
- Formatter panels (JSON / HTML / Bracket / SQL)
- Compare widget + navigation bar + markers
- Welcome tab (rebuilds on theme switch)

### 🖼️ Real screenshots on notepatra.org
Website hero showcase replaces the CSS illustration with two real screenshots: Welcome tab + AI Assistant. Captured via `xdotool` + `gnome-screenshot` from the actual v0.1.14 binary.

### 🖱️ System theme default
Fresh installs now follow the OS preference (macOS `AppleInterfaceStyle`, Windows `AppsUseLightTheme`, GNOME `color-scheme`) instead of forcing Dark. Falls back to Light when the OS signal can't be read. Settings → Theme gets a new "System (follow OS)" option.

### 🎨 Menu section headers
Tools menu now groups items under `── AI ──` · `── Search ──` · `── Workflow ──` · `── Formatters ──` section dividers. No more flat 20-item list.

### 🆘 Help → "How the AI Assistant works…"
Dedicated Help menu entry opens a rich-text dialog explaining all three backends (Ollama / llama.cpp / OpenAI-compat) with install commands and the CPU-auto-pick priority.

## What's unchanged from v0.1.14

- Windows MSI installer still ships (now `notepatra-0.1.15.msi`)
- macOS Tahoe launch fix from v0.1.12 (hardened runtime + entitlements)
- Word-level Compare + Project Search + Welcome tab + all v0.1.13/v0.1.14 features

## Installation

```sh
# Linux / macOS
curl -fsSL https://notepatra.org/install.sh | sh

# Windows
irm https://notepatra.org/install.ps1 | iex
```

Manual:
- 🐧 `notepatra-linux-x64.tar.gz` / `-arm64.tar.gz`
- 🍎 `notepatra-macos-arm64.dmg`
- 🪟 `notepatra-0.1.15.msi` · `notepatra-setup-0.1.15.exe` · `notepatra-windows-x64.zip`
