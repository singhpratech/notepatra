# Notepatra v0.1.0 — first public release

The first code editor built for the AI era. Native C++ + Rust binary that runs on Linux, macOS Apple Silicon, and Windows. **No Electron. No telemetry. No cloud. ~5 MB executable.**

## Highlights

- 🐧 🍎 🪟 **Three platforms** — Linux x64, macOS Apple Silicon (M1–M4), Windows x64
- ⚡ **5 MB native executable** (1.8 / 22 / 48 MB downloads with bundled Qt on Mac/Windows)
- 📑 **100+ file types** with 44 language lexers
- 🤖 **Local AI** via Ollama — JSON/HTML/Bracket fixers, Explain/Refactor/Test/Doc generation
- 🦀 **Rust-powered core** for memory-safe file I/O, search (Aho-Corasick), and diff (Myers)
- 🧪 **105/105 tests passing**

## Editor

- Tabbed editing with drag, reorder, color tags (7 colors + custom)
- 3 themes — Light, Dark, Monokai
- Session persistence — reopens all files, cursor positions, window size
- Crash recovery — auto-saves unsaved work every 10 seconds
- File change detection — notifies when external programs modify open files
- Memory-mapped file I/O — opens 2 GB files without truncation
- Macro recording (Ctrl+Shift+R / Ctrl+Shift+P)
- Code folding, bookmarks, brace matching (Ctrl+B), indent guides

## Languages (44 lexers)

Python, JavaScript, TypeScript, C, C++, C#, D, Java, HTML, PHP, CSS, XML, JSON, SQL (T-SQL/PL-SQL/MySQL/PostgreSQL/SQLite), Bash, Batch, Ruby, Perl, Lua, TCL, Fortran, Fortran77, MATLAB, Octave, IDL, NASM, MASM, Verilog, VHDL, TeX, PostScript, POV-Ray, Spice, AVS, Properties, PO, IntelHex, SRecord, Markdown, YAML, Diff, Pascal, CMake, Makefile, CoffeeScript

## Built-in plugins

- **JSON Tools** — Format, Minify, Fix+Format (Rust), AI Fix
- **HTML Tools** — Format (2/4 spaces), Minify, Fix+Format, AI Fix
- **Bracket Tools** — Check, Auto-Fix, AI Fix
- **SQL Formatter** — UPPERCASE/lowercase, configurable indent
- **Compare / Diff** — side-by-side Scintilla, Myers algorithm
- **Git Integration** — changed files panel, branch display, push/pull, gutter markers
- **Built-in Terminal** — opens as a tab, real bash/zsh/cmd
- **REST Client** — send HTTP requests, see responses with pretty JSON
- **Hex Editor** — color-coded hex dump
- **Markdown Converter** — selection to table, list, code block, bold, link, heading

## AI integration (local Ollama)

- AI Assistant (Ctrl+Shift+A) — Explain, Find Bugs, Refactor, Write Tests, Add Comments, Generate Docs, Optimize, Translate
- Hybrid AI Fix in JSON / HTML / Bracket tools — regex first, AI when regex isn't enough
- Default model: `qwen3.5:9b`. Also supports gemma, llama3.2, codellama, deepseek-coder-v2, mistral, starcoder2.
- Zero cloud, zero telemetry, zero API keys

## Search

- 5-tab Find/Replace dialog (Find, Replace, Find in Files, Mark, Go to)
- Normal, Extended (`\n`, `\r`, `\t`, `\xNN`), Regular expression modes
- Find / Replace All across all open tabs
- Find in Files with recursive directory search
- Search history (last 20)

## Installation

**Linux / macOS one-liner:**
```sh
curl -fsSL https://notepatra.org/install.sh | sh
```

**Windows PowerShell one-liner:**
```powershell
irm https://notepatra.org/install.ps1 | iex
```

Or grab the binaries directly from this release page.

## Verifying this release

Every release ships with **SHA-256 checksums**, **cosign signatures** (Sigstore + Rekor), and **SLSA build provenance attestations**. See [SECURITY.md](https://github.com/singhpratech/notepatra/blob/main/SECURITY.md) for the full verification guide. The `install.sh` and `install.ps1` scripts verify SHA-256 automatically.

```sh
# Quick verify
sha256sum -c SHA256SUMS --ignore-missing
```

## Known issues fixed in v0.1.1

If you installed v0.1.0 and hit any of these, upgrade to v0.1.1:

- 🪟 Windows: `notepatra.exe` had no embedded icon
- 🪟 Windows: Markdown / SQL / JSON files weren't syntax-highlighted (lexer regression in the QScintilla CMake wrapper used for v0.1.0)
- 🍎 macOS: `Notepatra.app` had no embedded icon
- 📝 JSON files with CRLF line endings were misclassified as JavaScript on every platform
