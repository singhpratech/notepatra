# Notepatra v0.1.107

Extension-routing fixes, a shortcut collision fix, and the big one: **DuckDB now ships in the Full downloads — and every platform now has both a Lite and a Full build.**

## Lite and Full for all three platforms

Until now, only Linux published a Full (`-full`) download; the macOS DMG and Windows MSI/zip silently shipped *without* WebEngine (we verified the published v0.1.106 Windows zip — it had zero WebEngine DLLs), even though the docs said otherwise. That's fixed honestly:

| Platform | Lite (default, bare) | Full (WebEngine + DuckDB) |
|---|---|---|
| Linux x64 / ARM64 | `notepatra-linux-*.tar.gz` | `notepatra-linux-*-full.tar.gz` |
| macOS | `notepatra-macos-arm64.dmg` | `Notepatra-full.dmg` |
| Windows | `notepatra-windows-x64.zip` + MSI | `notepatra-windows-x64-full.zip` + `notepatra-full-*.msi` |

- **Lite** stays small — just the editor, lexers, AI, Git, Data Analyst on CSV + in-memory SQLite. No WebEngine, no DuckDB.
- **Full** adds the QtWebEngine inline Vega-Lite chart renderer (the `generate_chart` tool) **and** the bundled **DuckDB v1.1.3** query engine (in-process Parquet / JSON / S3 / SQLite federation). The DuckDB library ships next to the binary in every Full download.

## Fixes

- **Extension routing (#556).** 13 file extensions were mapped twice in the lexer table and only resolved correctly by accident of hash ordering — `.hh` actually opened with the **Hack** lexer instead of **C++**. All 13 are now unambiguous and locked by tests: `.hh`→C++, `.pyx`/`.pxd`→Cython, `.scala`/`.sc`→Scala, `.groovy`/`.gradle`→Groovy, `.toml`→TOML, `.twig`→Twig, `.jinja`/`.jinja2`→Jinja, `.fish`→Fish, `.v`→Verilog.
- **Keyboard shortcut collision.** `Ctrl+Shift+K` was bound to **both** Delete Line and Uncomment Line (in the menu *and* the right-click context menu), so Delete Line was unreachable. Uncomment Line moved to **`Ctrl+Alt+U`**; `Ctrl+Shift+K` is Delete Line only.
- **DuckDB is Full-only.** The build option is now tied to the Full flavor — the default Lite binary can never link DuckDB, even if you pass `-DNOTEPATRA_USE_DUCKDB=ON`. Keeps Lite bare.
- **Docs honesty.** Corrected the claim that macOS/Windows already bundled WebEngine; the Lite-vs-Full pages now describe the real per-platform Lite and Full downloads.

## Notes

- Full downloads are larger than Lite (WebEngine + DuckDB add tens of MB). Pick Lite unless you want inline Vega-Lite charts or the DuckDB engine.
- The Data Analyst works out of the box on CSV + SQLite in **both** flavors; DuckDB is the extra engine in Full.
- No regressions: Lite 50/50 + Full 51/51 ctest green; the 13 extension routes are covered by unit tests.
