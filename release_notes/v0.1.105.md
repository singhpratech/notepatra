# Notepatra v0.1.105

**The diagram per-symbol colours from v0.1.104 now show up by default in the ER and System starter templates too — not just the flow chart.** Colour was never gated on diagram type; it has always worked on database cylinders and icon nodes exactly as on flow boxes. But only the *flow* starter demonstrated it, so picking "ER diagram" or "System design" from **New ▾** gave a monochrome template and the feature looked unavailable. This release closes that discoverability gap.

## What changed

No engine change — the colour parsing and rendering already covered every shape (box, pill, decision, database cylinder, icon) on every diagram type (`diagram flow|er|system`). What was missing was an *example*. Now all three starter templates ship a sensible default colouring, and the in-tool Help spells out that colour works everywhere.

## The change

1. **ER starter template** — entities are colour-grouped: green for master data (`Customers`, `Products`), blue for transactional data (`Orders`, `Order items`). Shows colour on `([…])` database-cylinder nodes.

   ```
   node customers ([Customers]) #2e7d32 :: "id, name, email, created_at"
   node orders    ([Orders])    #1565c0 :: "id, customer_id, total, placed_at"
   ```

2. **System starter template** — nodes are colour-grouped by tier: teal edge (`Browser`, `CDN`), blue app (`API gateway`, `App service`), purple data (`Cache`, `Primary DB`). Shows colour on `icon` nodes.

   ```
   icon user :user "Browser" #00838f :: "End-user web client"
   icon db   :database "Primary DB" #6a1b9a :: "Source of truth"
   ```

3. **Help** — the "Colour individual symbols" section now states colour works on every node type and every diagram (boxes, pills, decisions, database cylinders **and** icons, in flow, ER and system), with examples.

Colour remains **opt-in** — a node with no colour keeps the diagram palette, so the clean monochrome look is still the default for anyone who wants it.

## Test coverage

`test_diagram_view` adds `color_on_er_and_system_nodes`, asserting colour parses + survives alongside the shape and `::` hover on both a database-cylinder (`([…]) #hex`) and an icon (`:name "…" #hex`) node.

```
color_on_er_and_system_nodes
```

Full no-regression ctest is green (50/50). The ER and System coloured templates were verified by rendering each to PNG and inspecting the cylinder/icon fills and auto-contrast text.
