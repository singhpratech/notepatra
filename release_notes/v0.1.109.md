# Notepatra v0.1.109

**The full build drops its "Full" name tag.** The default (DuckDB-bundled) build now self-identifies simply as **Notepatra**; only the bare build keeps a **Lite** suffix so you can tell it apart.

## What changed

`notepatra --version`, the window title bar, and the About dialog used to label the full build "Notepatra Full". Since the full edition is the default and most-featured build, that qualifier just added noise. Now:

| Build | In-app name |
|---|---|
| Full (DuckDB bundled) | **Notepatra** |
| Lite (bare) | **Notepatra Lite** |
| Full, cloud-free | **Notepatra Local AI** |
| Lite, cloud-free | **Notepatra Local AI Lite** |

Only the lite editions carry an edition suffix — it's the marker that tells you a bare build has no DuckDB engine.

## Notes

- **Naming only.** The Lite vs Full *downloads* are unchanged — Full still bundles the DuckDB v1.1.3 engine on every platform, Lite is still bare. Features, dependencies, and download sizes are identical to v0.1.108.
- The internal application name stays `Notepatra` (it drives the config / settings paths), so your settings carry over.
- No regressions: 51/51 ctest green, with both the Lite and Full `--version` strings verified.
