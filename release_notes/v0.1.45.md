# Notepatra v0.1.45 — hotfix on top of v0.1.44

**Released**: 2026-05-08

Two issues from v0.1.44 reported by the user — both fixed.

## What v0.1.44 missed

v0.1.44 added a red ✕ close button + Notepad++-style stacked history to
the `ProjectSearch` tab (Ctrl+Shift+G). But **Find in Files**
(Ctrl+Shift+F) actually shows results in a different widget — the
**bottom-docked `SearchResultsPanel`** — which still had no close
button and still wiped its history on every new search. v0.1.44's
comment menu also only had `Toggle Line/Block Comment`, not separate
explicit `Comment` / `Uncomment` items like Notepad++.

## Fixes in v0.1.45

### Bottom-docked Search Results panel — close + history

The panel header is now a row with `Search Results` on the left and a
**red ✕ close button** on the right (theme-independent `#E81123`, white
on red on hover, matching the AI dock + Project Search). Click the ✕ →
panel hides; history is kept until you reopen.

Each Find All / Find All in All Open Documents call becomes a new
top-level **session** row:

```
🔎  Search "host" — 32 hits in 1 file · 04:18:22
       C:/Users/Anamika-PC/rdp-setup.ps1 (32 hits)
            Line  10:    $pwd1 = Read-Host …
            Line  11:    $pwd2 = Read-Host …
            …
🔎  Search "password" — 4 hits in 1 file · 04:14:05
       C:/Users/Anamika-PC/rdp-setup.ps1 (4 hits)
            …
```

Previous sessions auto-collapse so the new one stands out. Capped at
10 sessions; the oldest is pruned when the cap is exceeded.

### Explicit Comment / Uncomment menu items

The right-click context menu and the Edit → Comment/Uncomment submenu
now have **six** items, matching Notepad++:

| Action | Shortcut |
|---|---|
| Toggle Line Comment | `Ctrl+/`, `Ctrl+Q` |
| Toggle Block Comment | `Ctrl+Shift+Q` |
| **Comment Line** (always adds) | `Ctrl+K` |
| **Uncomment Line** (always strips) | `Ctrl+Shift+K` |
| **Comment Block** (always wraps) | — |
| **Uncomment Block** (always unwraps) | — |

`Ctrl+K` / `Ctrl+Shift+K` match Notepad++'s defaults. The new
`uncommentLine` only strips when the comment marker is the FIRST
non-whitespace token on the line, so it can't mangle inline `--` in SQL
expressions or `#` in PowerShell strings.

All comment menu items grey out (with `(no syntax for X)` on the toggle
labels) when the file's language has no known comment syntax — Plain
Text, Diff, etc.

- `CMakeLists.txt` — `0.1.44 → 0.1.45`.
