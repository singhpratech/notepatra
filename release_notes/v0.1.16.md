# Notepatra v0.1.16 — modern AI dock + lightning-fast search

**Released:** 2026-04-20

v0.1.16 is a focused quality pass on the two features users reach for most: the **AI Assistant** and **Project Search**. The AI panel finally feels modern; search is genuinely lightning-fast thanks to the Rust aho-corasick engine (the one the README was already claiming but didn't actually use until this release).

---

## Highlights

### 🤖 AI Assistant — side-dock with full workspace awareness

- **Persistent right-side dock.** `Ctrl+Shift+A` toggles the dock instead of spawning a new editor tab. One chat, always in the same place, conversation survives tab switches.
- **Whole-workspace context.** Every prompt carries the selection, full current file, excerpts of every other open editor tab, the workspace root, and a flat listing of every file under it (with `.git` / `node_modules` / `target` / etc. filtered). The AI can reference files you haven't opened yet.
- **Coding Mode is now unmistakable.** Top strip turns accent-green with a "⌘ Coding Mode" badge and underline; chat body flips to monospace; quick-action grid hides for a clean chat. Chat history is preserved when toggling modes — no resets.
- **Per-code-block "⧉ Copy code" buttons** inside every response (ChatGPT-style). Whole-response pill stays in the bubble header.
- **Cleaner panel chrome.** Removed redundant "Backend:" / "Model:" labels; "Coding Mode" → "Coding", "Show thinking" → "Think". The 8-button quick-action grid + Insert/Replace/Copy row collapse behind a `▸ Quick actions` chevron.

### 🔎 Project Search — 10–50× faster, actually Rust-powered now

- **Dir walk pruning.** Skips `.git`, `.svn`, `.hg`, `node_modules`, `bower_components`, `target`, `build`, `dist`, `out`, `bin`, `obj`, `__pycache__`, `.venv`, `.cache`, `.tox`, `.next`, `.nuxt`, `.turbo`, `.gradle`, `.idea`, `.vscode`, `vendor`, `Pods`, `DerivedData`, `.terraform`, `coverage` up-front. On this repo alone: **3,512 files walked → 212.** Matches ripgrep's default skip list.
- **Rust aho-corasick is finally wired in.** Literal searches on files ≤ 8 MB go through `RustCore::findAll()` — the same aho-corasick crate ripgrep uses — mapping byte-offsets to `(line, col)` via `upper_bound` over a pre-built line-start index. Regex searches and files > 8 MB still stream line-by-line so 2 GB logs stay RAM-safe.
- **Parallel file scanning** via `QtConcurrent::blockingMap`. Uses every CPU core; roughly 3–4× faster than the serial version on a 4-core laptop.

### 🖥️ Terminal — interactive CLIs work in-line

- `claude`, `codex`, `aider`, `gh`, `python` / `ipython`, `node`, `ssh`, `mosh`, `psql`, `mysql`, `sqlite3`, `gdb`, `lldb` now get a real TTY via `script(1)` wrapping and run **inside** the Notepatra terminal. Input box flips to stdin-feed mode; prompt changes to `<cmd> ▷`.
- Fullscreen TTY apps (`vim`, `nvim`, `nano`, `top`, `htop`, `btop`, `less`, `more`, `man`, `tmux`, `screen`) still hand off to the system terminal emulator — a line-based output view genuinely can't host alternate-screen mode.
- Alignment fixes for streamed output: replaced `QTextEdit::append()` with cursor-positioned `insertHtml + <br>`. Bare `cd` now means `$HOME`.

### 🧪 CI back to green

- `test_llamacpp` and `test_ai_context` were registered with CTest but missing from the explicit `cmake --build --target` list in `.github/workflows/build.yml`, so every push landed red with `test_llamacpp ***Not Run***`. Fixed. Linux + Linux-ARM regression suites pass again.
- New `test_ai_context` unit test — 21 assertions on the workspace-context block builder. Runs headless; no Qt Widgets dependency.

### 🎨 Welcome tab

- Notepatra logo now shows above the "Welcome to Notepatra" headline. `loadWelcomeLogo()` tries `QIcon::fromTheme("notepatra")` first, then falls back to exe-relative and `~/.local/share/icons/hicolor` paths.

### 🖼️ Website

- `docs/screenshots/tour.gif` — the "Notepatra in 60 seconds" hero — is now a real captured animation (Welcome → editor → Project Search with live results → AI Assistant with Ollama auto-detected) replacing the placeholder play button.

## Installation

### Linux (AppImage)

```bash
wget https://github.com/singhpratech/notepatra/releases/download/v0.1.16/Notepatra-0.1.16-linux-x86_64.AppImage
chmod +x Notepatra-0.1.16-linux-x86_64.AppImage
./Notepatra-0.1.16-linux-x86_64.AppImage
```

### macOS

```bash
curl -fsSL https://github.com/singhpratech/notepatra/releases/download/v0.1.16/Notepatra-0.1.16.dmg -o ~/Downloads/Notepatra-0.1.16.dmg
open ~/Downloads/Notepatra-0.1.16.dmg
# Drag Notepatra.app → Applications, then run the installer's one-liner if Gatekeeper blocks first launch.
```

### Windows

Pick one — same binary, different packaging:

- **MSI** (Windows Installer) — `Notepatra-0.1.16.msi`
- **NSIS installer** — `Notepatra-Setup-0.1.16.exe`
- **Portable ZIP** — `Notepatra-0.1.16-windows-x64.zip`

All artifacts are attached to this release page.

## Upgrade notes

- If you had Coding Mode pinned on in v0.1.15, the same config carries over — but the behaviour is cleaner now: explorer only opens when Coding Mode is explicitly ticked (previously opened automatically on Ctrl+Shift+A).
- `Ctrl+Shift+A` now opens the AI dock rather than creating a new "AI Assistant" editor tab. If you had an AI Assistant tab open from v0.1.15, just close it — the dock replaces it.
- Project Search results format is unchanged; bookmarks / saved queries (if any) still apply.
