# Notepatra v0.1.21 — Windows UI polish (spacing collisions + close ✕ clipping)

**Released:** 2026-04-25

A small UI polish release on top of v0.1.20. Bundles two Windows-specific layout fixes:

1. **Option rows on every tool panel ran widgets together on Windows.** The visible bug was `"UPPERCASE keywordsIndent:"` on the SQL Formatter — the checkbox label and the next QLabel had no space between them. Same shape in Find/Replace, Compare toolbar, and the JSON / HTML / Bracket formatters.
2. **The AI dock close ✕ glyph clipped on Windows fonts.** The button was 28×28 with 0 8px horizontal padding — only 12 px of room for an 18 px glyph. On Windows the right edge of the × visibly cropped against the hover background.

No Linux or macOS user sees a difference. Windows is what changes.

---

## Highlights

### 🪟 Windows UI polish — collisions and clipped glyphs fixed

- **Tool-panel option rows no longer collide on Windows.** `QHBoxLayout` default spacing is ~6 px on Linux's Fusion / GTK style but **0 px** on Windows Vista / Windows 11 styles. Any row that didn't call `setSpacing()` was relying on Linux's default and visibly collapsing on Windows. Explicit `setSpacing(8|10|12)` added on every collision-prone row:
  - **SQL Formatter** — Dialect / UPPERCASE checkbox / Indent / Format / AI Fix / Copy Output row.
  - **JSON / HTML / Bracket formatters** (FormatPanel) — Show Diff / Copy Output button row.
  - **Compare toolbar** — Prev / Next / Recompare / Unlock Editing / Ignore-spaces / Ignore-case / Ignore-empty-lines / Stats / Close.
  - **Find/Replace dialog** — Find tab options, Replace tab options, Find-In-Files options, Search-Mode group, Mark tab options.
- **AI dock close ✕ no longer clips on Windows.** Switched the glyph from `U+00D7` ('×' multiplication sign) to `U+2715` ('✕' a real X), widened the button 28→36 px, zeroed padding, dropped the font 18→16 px / weight 500→600. The glyph now centres cleanly on every DPI / font fallback.
- **Compare ✕ Close button widened 70 → 84 px.** The fixed width was tight on Windows where button-chrome padding ate into the `"✕ Close"` label.

## Upgrade notes

- The in-app updater from v0.1.20 will pick this up automatically — and because v0.1.20 already shipped the close-before-install fix, the Windows update will close Notepatra cleanly before msiexec runs. No manual app-kill needed.
- Linux / macOS / iPad (AppImage / DMG) builds are unchanged in behaviour from v0.1.20; the binaries are rebuilt from the new commit but the only differences are Windows-side.
- No config changes, no FFI changes, no schema changes — purely Qt layout adjustments + one button glyph swap.
