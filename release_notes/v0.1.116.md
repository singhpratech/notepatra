# Notepatra v0.1.116

**Two focused fixes: the Compare view's changed-word highlight is readable again, and the in-app updater now always fetches the installer matching your edition. No new features, same bare binary, no new dependencies. Every change was adversarially verified — including one attempted packaging change that was caught and pulled back because it would have broken Windows upgrades.**

### Fixed — Compare view readability
- The changed-**word** highlight in the Compare tab used a deep red/green fill at high opacity that buried the text underneath. It's now a **soft wash with a crisp red/green outline** — the changed word is still clearly marked (and clearly red vs green), but the text reads through cleanly. Verified to pass WCAG AA contrast in **Light, Dark, and Monokai** themes. Only the inline fill opacity changed; the outline, colors, and all line/amber backgrounds are untouched.

### Fixed — in-app updater picks the right edition
- The updater's release-asset selection scored every installer variant identically, so which one you were offered depended on the order GitHub happened to list them — a **Full** user could be handed a **Lite** installer (or a cloud-free user the wrong one), and vice-versa. It now **deterministically selects the installer matching this build's edition** (Lite/Full × cloud/local-AI) across **all three platforms** (Windows MSI, macOS DMG, Linux tarball/AppImage), regardless of asset order. The download → SHA-256 verify → launch path is unchanged; nothing about *where* it downloads changed.

### Known / deferred
- This release does **not** change Windows MSI upgrade behavior. A separate report — the in-app update prompting for the *previous* version's MSI in the Downloads folder during a Windows upgrade — was investigated: the obvious packaging fix (rescheduling the MSI major-upgrade) was found, on review, to risk **deleting the freshly-installed Qt DLLs on every Windows upgrade** (per-build component-GUID churn) while likely not fixing the prompt at all, so it was **not shipped**. The proper fix requires stable component GUIDs plus a real Windows upgrade test and is tracked as a follow-up.

Same bare binary, no new dependencies. Full offscreen ctest 70/70; the updater picker fix is covered by 17 new order-independence / edition assertions.
