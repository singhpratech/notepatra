# Notepatra v0.1.75 — Runtime font-pack downloader

Released: 2026-05-11

User-facing new feature on top of v0.1.74. Adds an in-app font
installer so users can pull in ~27 premium open-source fonts (JetBrains
Mono / Fira Code / Cascadia Code / IBM Plex / Geist / Monaspace / Inter
/ Source Serif / …) on demand. The bare binary stays at ~9 MB — fonts
ship via the same on-demand pattern as the Charts Pack / DuckDB
extensions.

---

## What's new

### Settings → Manage Fonts…

A new dialog lives under the existing `Settings` menu (right after
Preferences). It lists every entry from the curated catalogue grouped
into four sections:

- **Code · Monospace** — JetBrains Mono, Fira Code, Cascadia Code,
  Source Code Pro, IBM Plex Mono, Hack, Geist Mono, Inconsolata,
  Roboto Mono, Fira Mono, Noto Sans Mono, Space Mono, Anonymous Pro
- **UI · Sans-serif** — Inter (variable), Roboto, Manrope
- **Serif · Prose** — Source Serif 4 (variable), Merriweather
- **Display · Distinctive** — Victor Mono Italic, Comic Mono

Each row shows family · variant · approximate size · license · origin
· installed/not-installed status. Tick the ones you want, click
**Install selected**, and the dialog:

1. Downloads each TTF/OTF from its pinned upstream HTTPS URL to
   `~/.local/share/notepatra/fonts/` (cross-platform via
   `QStandardPaths::AppDataLocation`).
2. Calls `QFontDatabase::addApplicationFont()` immediately so the
   font is available to the running process — **no restart needed**.
3. The existing `notepatraDefaultCodeFamily()` chain in `src/fonts.h`
   already orders dozens of candidate families in priority order, so
   the new fonts simply slot into the lookup. Pick any installed font
   as the editor font via **Settings → Preferences → Editor → Font**.

A **Remove selected** button deletes the file from disk. (The Qt
process keeps the family registered until restart — that's a Qt
limitation, not a bug.)

### How the binary stays lite

No bytes are bundled. Manifest entries point at pinned upstream tags
on GitHub:

```cpp
{"JetBrains Mono", "Regular", "JetBrainsMono-Regular.ttf",
 "https://github.com/JetBrains/JetBrainsMono/raw/v2.304/fonts/ttf/JetBrainsMono-Regular.ttf",
 274000, "OFL 1.1", "JetBrains", Category::CodeMono},
```

The bare Notepatra binary doesn't grow — fonts only land on disk when
the user explicitly asks for them. Compared to the alternative of
bundling 27 TTFs (~10 MB binary growth), this honours the project's
*"bare binary stays small — heavy features on-demand"* rule.

### Licensing

Every entry is **SIL OFL 1.1**, **Apache 2.0**, or **MIT** — all
royalty-free and freely redistributable. The dialog displays the
license per row so the user can see what they're installing.

### Cloud-free build (`notepatra-local-ai`)

The font downloader makes HTTPS requests to `github.com` /
`raw.githubusercontent.com`. These are **not** cloud LLM endpoints and
are **not** refused by the `NotepatraNetworkPolicy::isPrivateNetworkHost()`
gate. That said, regulated / air-gapped users typically don't want
their app reaching out to public GitHub either — for those
environments, the workflow is:

- Download fonts on a connected machine, copy `*.ttf` files into
  `~/.local/share/notepatra/fonts/` manually.
- Notepatra's startup hook (`NotepatraFontPack::loadInstalledFonts()`)
  scans that directory on every launch and registers every TTF/OTF
  it finds — no downloader interaction required.

## Files added / changed

- **New: `src/fontpack.{h,cpp}`** — manifest (27 entries),
  `loadInstalledFonts()` startup scanner, `Installer` queue with
  progress / cancel signals, `isInstalled()` / `uninstall()` helpers.
- **New: `src/fontpack_dialog.{h,cpp}`** — Qt5 dialog with grouped
  `QTreeWidget` (category headers + per-font rows with checkboxes),
  install / remove / select-all buttons, progress bar.
- **Wiring: `src/main.cpp`** — `NotepatraFontPack::loadInstalledFonts()`
  call right after `QApplication` construction, before
  `setFont(notepatraUiFont())` so the chain in `src/fonts.h` sees the
  newly-loaded families when resolving the default UI/code font.
- **Wiring: `src/mainwindow.cpp`** — `Settings → Manage Fonts…`
  action that opens `FontPackDialog` and re-applies the editor font
  config afterwards.
- **New test: `test_fontpack.cpp`** — 23 sub-checks. Manifest
  validity (no duplicate filenames, all-HTTPS URLs, every entry has a
  license + origin + category, expected industry-standard families
  present), path helpers (`fontsDir()`, `localPath()`), and an
  end-to-end load test that copies a system TTF into `fontsDir()` and
  asserts `loadInstalledFonts()` registers it.
- **CMakeLists**: VERSION bump 0.1.74 → 0.1.75; `test_fontpack`
  target added with labels `unit;fontpack;v0175`.
- **`docs/regression-log.md`** — new v0.1.75 entry.

29/29 ctest pass (up from 28).

## Compatibility

- Linux (.deb / .rpm / AppImage) — unchanged binary structure.
- macOS DMG — unchanged.
- Windows NSIS / MSI — unchanged (Component GUIDs from v0.1.74 carry
  forward; the local-ai MSI upgrade fix from v0.1.74 stays in place).
- Existing user config / sessions / chat history — unchanged. The
  font-pack directory is created lazily; if you never open
  `Settings → Manage Fonts…`, no behaviour changes vs v0.1.74.
