# Notepatra v0.1.110

**AI coding assistant — a trust & clarity pass.** Driven by a deep usability audit of the assistant (which graded it C+); this batch of fixes lifts it to B- by resolving the two worst trust failures and the single biggest legibility gap. No new dependencies, same bare Lite binary, download sizes unchanged.

## What changed

- **Your mode is always readable.** The assistant header now shows your full effective posture, not just the intent: `AI · CODING · COMPOSE` (review-before-write, teal) or `AI · CODING · AGENT` (writes hit disk live, red). You no longer have to infer from three highlighted buttons whether the AI is about to edit your files. The header updates the instant you switch segment and stays correct across theme changes.
- **Coding starts in the safe lane.** Coding mode now defaults to **Compose** (propose-then-review), not autonomous **Agent**. Previously, working in Compose, closing the dock, and reopening could silently drop you back into autonomous disk-writes. The cold default is now the safe one; you can still choose Agent explicitly.
- **"Apply" tells you it worked.** Applying a proposed multi-file edit now marks each written file with a green **✓ applied** badge, drops a "✓ Applied N files" confirmation, **disables re-apply** on applied rows, and greys out the Apply buttons when nothing is pending. No more wondering whether the write landed — or silently re-writing every file with a second click.
- **Inline edit (Ctrl+I) is first-class.** It now uses the **model you selected** in the AI panel instead of a fixed small default (fixing a no-hardcoded-model rule), and it groups its change as **one undo action** so a single Ctrl+Z cleanly reverts the whole AI edit — the "safe to try" contract.

## Notes

- **UX / state changes only.** No binary, dependency, or download-size change. Lite stays bare. The new `✓` is a plain dingbat (U+2713), not a colour-emoji, so no Linux tofu risk.
- The **dock-hidden-on-launch** behaviour is intentionally unchanged (the AI opens only when you click it — a long-standing preference).
- No regressions: **51/51 ctest** green (both Lite and Full builds), plus a new integration test for the apply-confirmation contract.
- Still ahead in the audit's roadmap (future releases): codebase context transparency, a Composer-Apply rollback, and an Agent-mode confirmation gate.
