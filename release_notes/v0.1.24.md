# Notepatra v0.1.24 — Windows mojibake cleanup ("Open with" menu + PowerShell installer banner)

**Released:** 2026-04-25

A small, Windows-only follow-up to v0.1.23. Two distinct UTF-8-vs-codepage bugs that showed up on a fresh Windows 11 install — both now fixed.

---

## Highlights

### 🪟 Windows "Open with" menu — no more `Notepatra â€" native code editor`

**Root cause:** `resources/notepatra.rc` was saved as UTF-8 without a BOM and contained two non-ASCII characters in resource strings — an em-dash (`—`, UTF-8 `0xE2 0x80 0x94`) in `FileDescription` and a copyright sign (`©`, UTF-8 `0xC2 0xA9`) in `LegalCopyright`. The Microsoft Resource Compiler (`rc.exe`) defaults to the system codepage (cp1252 on US-English Windows) when reading source files without a BOM, so each multi-byte UTF-8 sequence got reinterpreted byte-by-byte as cp1252 characters (`â€"` for the em-dash, `Â©` for the copyright). Those wrong characters then got transcoded into UTF-16 and embedded in the `VERSIONINFO` resource block — which Windows Explorer then reads back as Unicode and displays verbatim in the "Open with" menu and File Properties.

**Fix:** ASCII-only resource strings.

```diff
- VALUE "FileDescription",  "Notepatra — native code editor for the AI era"
+ VALUE "FileDescription",  "Notepatra - native code editor for the AI era"
- VALUE "LegalCopyright",   "© 2026 Prateek Singh. GPL-3.0."
+ VALUE "LegalCopyright",   "Copyright 2026 Prateek Singh. GPL-3.0."
```

ASCII bytes survive any codepage interpretation untouched, so this works regardless of which resource compiler ships with the user's MSVC / MinGW toolchain or how their CI is configured.

### 🪟 `irm https://notepatra.org/install.ps1 | iex` — no more `â`/`âˆ` banner garbage

**Root cause:** Windows PowerShell 5.1 — which is what `irm | iex` actually runs in on a default Windows 11 install — initialises `[Console]::OutputEncoding` to the legacy OEM codepage (typically cp437 in a `cmd.exe`-launched session, cp1252 in some terminal emulators). When `Write-Host` is handed a Unicode string containing box-drawing characters (`╔═╗║`), em-dashes, or `✅`, PowerShell encodes the string with that legacy codepage before writing to stdout — and every multi-byte UTF-8 character gets shredded into multiple stand-alone garbage glyphs.

**Fix:** Two complementary changes in `docs/install.ps1`.

1. Force the console encoding to UTF-8 at the top of the script, wrapped in a `try {} catch {}` so it degrades gracefully on legacy hosts:
   ```powershell
   try {
       [Console]::OutputEncoding = [System.Text.Encoding]::UTF8
       $OutputEncoding = [System.Text.Encoding]::UTF8
   } catch {}
   ```
2. Replace the Unicode box-drawing banner with ASCII (`+===+|+`) so even if the encoding setup fails for some reason, the banner still renders cleanly. This change is purely cosmetic — but it means a user on a misconfigured system won't see "Notepatra Installer" buried in a wall of `â`s.

The em-dashes in `Write-Host` warning messages and the final `✅` success line still use Unicode, but those now render correctly because of step 1.

## Scope

- **No C++ source changes.** This release is purely a text-encoding fix.
- **No behaviour changes.** Same binaries, same UI, same features as v0.1.23.
- **Linux / macOS users are unaffected.** The `.rc` file is only compiled on Windows, and `install.sh` runs in terminals that default to UTF-8 on those platforms.

## Installation

### Linux (AppImage)

```bash
wget https://github.com/singhpratech/notepatra/releases/download/v0.1.24/Notepatra-0.1.24-linux-x86_64.AppImage
chmod +x Notepatra-0.1.24-linux-x86_64.AppImage
./Notepatra-0.1.24-linux-x86_64.AppImage
```

### macOS

```bash
curl -fsSL https://github.com/singhpratech/notepatra/releases/download/v0.1.24/Notepatra-0.1.24.dmg -o ~/Downloads/Notepatra-0.1.24.dmg
open ~/Downloads/Notepatra-0.1.24.dmg
```

### Windows

- **MSI** — `Notepatra-0.1.24.msi`
- **NSIS installer** — `Notepatra-Setup-0.1.24.exe`
- **Portable ZIP** — `Notepatra-0.1.24-windows-x64.zip`

### One-command installer scripts

```bash
# Linux, macOS
curl -fsSL https://notepatra.org/install.sh | sh

# Windows PowerShell
irm https://notepatra.org/install.ps1 | iex
```
