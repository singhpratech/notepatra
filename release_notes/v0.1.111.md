# Notepatra v0.1.111

**AI coding assistant — the "lovable agent" wave.** A deep usability grade put the assistant at B-; this wave ships the four features that move it toward A-: a confirmation gate before the agent writes to disk, full transparency into the context that's sent, one-click rollback of applied edits, and a real Myers diff for inline edits. No new dependencies, same bare Lite binary, download sizes unchanged.

## What changed

- **The agent asks before it writes (Agent mode).** In the autonomous **Agent** segment, a `write_file` / `apply_diff` no longer hits disk silently — it shows an inline card with the **diff** of what it wants to write and three choices: **Approve**, **Reject**, or **Approve all writes this turn**. Reads (`read_file`, `search`, `git …`) are never gated, so the agent still moves fast; only disk mutations pause for you. Reject tells the model you declined so it stops retrying. (Compose mode is unchanged — it already routes through the Edit Plan for review.)
- **You can see exactly what context is sent.** A **Context** strip above the input shows what codebase context will be prepended to your message — the current file, open tabs, the workspace file tree — with its **size in KB**. Click it to open a read-only view of the *literal bytes* that will be sent, with per-source **Include** toggles to exclude the current file, other tabs, or the tree from the next message. What the popover shows is byte-for-byte what gets sent — there is exactly one assembler, so the preview can't drift from reality. Credentials are redacted in the preview just as they are on send.
- **Undo an applied edit.** After you Apply a proposed multi-file edit, an **Undo apply** button restores those files to their previous content in one click. It's **drift-protected**: if you edited a file after applying it, Notepatra warns and lets you choose *Revert anyway / Skip changed files / Cancel* rather than silently destroying your work. Reverting a file the agent *created* deletes it.
- **Inline edit (Ctrl+I) now shows a real diff.** The side-by-side diff in the Ctrl+I rewrite dialog now uses the real **Myers diff** (the same engine the Edit Plan uses) instead of a naive line-by-line compare, so a one-line change highlights exactly one line instead of reddening the whole block. The diff tints are now **theme-aware** (they were light-only before — a dark-mode readability bug).

## Notes

- **UX / behaviour changes only.** No binary, dependency, or download-size change. Lite stays bare. New UI uses plain dingbats (✓ ↶ ▸), never colour-emoji, so no Linux tofu.
- The Agent write-gate is the authorized behaviour change this wave: Agent mode is now confirm-before-write by default. "Approve all this turn" re-arms each new message — there is no session-wide "always allow".
- No regressions: **52/52 ctest** green (Lite and Full), including a new Myers-diff test and an extended Edit-Plan rollback-state test, plus a parallel adversarial review of every changed file.
- Roadmap still ahead (future waves): a `run_command` tool to close the agent loop, keyboard accept/reject on edit hunks, and semantic workspace retrieval.
