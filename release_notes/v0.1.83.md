# v0.1.83 — stale-version-ref sweep + release-check gate

**Date:** 2026-05-14

v0.1.82 shipped the security hardening sweep cleanly, but the website had eleven user-facing strings still pointing at v0.1.81 (hero badge, sticky download CTA aria-label + visible text, main download section label, both "Get Notepatra v…" buttons, JSON-LD FAQ "Latest v0.1.81 download sizes" + "as of v0.1.81", page-body lead "As of v0.1.81: 226 file types", and the lexer paragraph). The website-release-detail-policy memory existed since v0.1.76 — it failed because it was advice, not a gate.

## Why a tag for a docs-only change

The user-facing website was misrepresenting the latest release for ~25 minutes after v0.1.82 shipped (CI rebuild window for GitHub Pages). The cleanest way to make the website honest is to make v0.1.83 the version the page actually points at, AND ship the gate that prevents recurrence in the same commit.

### New gate — stale-version-ref scanner
`scripts/stale-text-check.sh` now has a "stale version-ref sweep" section. It enumerates the user-facing phrases that MUST always contain the current `$VERSION` (hero badge / sticky CTA / download buttons / FAQ / docs.html tag header / "as of v…" prose / "Latest release: v…" / "Latest vX.Y.Z download sizes" / JSON-LD `softwareVersion`) and fails the release if any of them contains a stale version after the bump.

Implementation: each phrase template uses a `__V__` placeholder substituted twice — once with the current version's literal (dot-escaped for `grep -E`), once with the any-version regex `0\.1\.[0-9]+`. Match counts are compared. If the count of "any-version" matches exceeds the count of "current-version" matches, the script reports the stale occurrences and exits non-zero.

This is the canonical worked example of the **memory → gate promotion** pattern: a check that has fired the same way three times across releases (v0.1.59 App About body, then v0.1.81 → v0.1.82 cargo-clippy drift, now v0.1.82 → v0.1.83 website strings) belongs in the gate, not in the operator's head.
