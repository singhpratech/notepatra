# Notepatra v0.1.76 — Expanded chart catalogue + AI chart-selection guidance

Released: 2026-05-11

Data Analyst mode goes from 4 chart types to **12**, and the AI now
picks the right one based on data shape instead of defaulting to `bar`
for everything. All new chart types render via QtCharts — no
WebEngine required, so they work in the lite build too.

---

## What's new

### Chart modal viewer with PNG export

Every inline chart in the AI chat transcript now has a small **⛶ Expand**
button in the top-right corner. Click it and a 960×640 modal opens
with the chart re-rendered at full size, plus three actions:

- **Save as PNG…** — opens a file picker (defaults to `~/Pictures/`)
  and writes a HiDPI-correct PNG of the chart.
- **Copy image** — copies the rendered chart pixmap to the system
  clipboard for paste into other apps.
- **Close** — dismisses the modal.

The modal re-renders from the original spec (independent QChartView),
so the inline thumbnail keeps its own state and tooltips. Works for
every QtCharts-backed chart type (all 12 in the catalogue).

Files: `src/chart_modal.{h,cpp}` (new).

### Hover tooltips on every chart

QtCharts emits hover signals out of the box but doesn't display
anything. v0.1.76 wires `QToolTip::showText()` to every series on
every chart:

- Bar / stacked-bar / grouped-bar: `<series>\n<category>: <value>`
- Line / area / scatter: `<series>\nx <x> · y <y>`
- Pie / donut: `<label>\n<value> (<percentage>%)`
- Boxplot: full 5-quantile summary (min · Q1 · median · Q3 · max)

Hover tooltips fire in chat thumbnails AND in the expand modal.

### 8 new chart types

`src/chartrender.cpp` previously accepted only `line` / `bar` / `pie`
/ `scatter`. v0.1.76 adds:

| Type | Use it when |
|---|---|
| **`area`** | Time-series and magnitude / volume matters (filled below the line). |
| **`horizontal-bar`** | Many categories or long category labels — bars run left-to-right so labels are readable. |
| **`stacked-bar`** | Multiple value columns that should sum to a per-category total (composition over time). |
| **`stacked-horizontal-bar`** | Same as stacked-bar but bars run horizontally for long labels. |
| **`grouped-bar`** | Multiple value columns shown side-by-side per category (comparison, not composition). |
| **`donut`** | Composition of a whole, ≤ 6 parts. Less critized than solid pie. |
| **`histogram`** | Distribution of ONE numeric variable. Notepatra auto-bins. |
| **`boxplot`** | Distribution comparison across groups (min / Q1 / median / Q3 / max). |

Every type renders via QtCharts (`QAreaSeries`, `QHorizontalBarSeries`,
`QStackedBarSeries`, `QHorizontalStackedBarSeries`, `QBoxPlotSeries`),
so they work in the **lite build** (~9 MB binary, no WebEngine) AND
the full build. The WebEngine `generate_chart` Vega-Lite tool path is
unchanged for advanced specs (heatmaps, layered charts, geo-shapes).

### AI chart-selection guidance

Previously the Data Analyst system prompt listed only four chart types
and said "emit a chart when useful." The AI defaulted to bar charts
for almost everything.

v0.1.76 rewrites that section with **explicit data-shape → chart-type
mapping**:

```
Time series, ordered numeric x, one y       → line
Time series, magnitude matters              → area
Categorical x, one numeric y, ≤ 8 cats      → bar
Categorical x, one y, > 8 or long labels    → horizontal-bar
Categorical x, multiple y, comparison       → grouped-bar
Categorical x, multiple y, parts of whole   → stacked-bar
Composition of a whole, ≤ 6 parts           → donut (prefer over pie)
Composition of a whole, > 6 parts           → stacked-bar
Two numeric variables, correlation          → scatter
One numeric variable, distribution shape    → histogram
Distribution comparison across groups       → boxplot
```

Now when the user asks "show me how X is distributed," the AI reaches
for `histogram` instead of guessing. When they ask "compare quarters
across regions," they get `grouped-bar` instead of stacked or single.

### Spec formats

Single-series (existing pattern — `line` / `area` / `bar` /
`horizontal-bar` / `scatter`):

```chart
{"type":"area","title":"Revenue by quarter","x":"quarter","y":"revenue",
 "data":[{"quarter":"Q1","revenue":1200},{"quarter":"Q2","revenue":1850}]}
```

Multi-series — `grouped-bar`, `stacked-bar`, `stacked-horizontal-bar`
take `y` as an **array** of value column names:

```chart
{"type":"grouped-bar","x":"region","y":["q1","q2","q3","q4"],
 "data":[{"region":"NA","q1":120,"q2":140,"q3":160,"q4":180},
         {"region":"EU","q1":100,"q2":110,"q3":130,"q4":150}]}
```

Histogram — Notepatra auto-bins (default 20 bins, configurable via
`bins`):

```chart
{"type":"histogram","x":"score","bins":15,
 "data":[{"score":67},{"score":72},...]}
```

Boxplot — Notepatra computes min / Q1 / median / Q3 / max per group:

```chart
{"type":"boxplot","x":"product","y":"price",
 "data":[{"product":"A","price":10},{"product":"A","price":12},
         {"product":"B","price":20},...]}
```

Donut — pie with hole:

```chart
{"type":"donut","label":"category","value":"share","data":[...]}
```

## Compatibility

- Existing `line` / `bar` / `pie` / `scatter` charts render identically.
- No spec format changes — multi-series specs use `y: [...]` array
  which is a NEW format, not a breaking change.
- Lite build (`-DNOTEPATRA_WITH_WEBENGINE=OFF`) renders all 12 chart
  types via QtCharts. Full build (`-DNOTEPATRA_WITH_WEBENGINE=ON`)
  additionally handles advanced Vega-Lite specs via the
  `generate_chart` tool path.
- Windows MSI Component-GUID fix from v0.1.74 + AI dock fixes from
  v0.1.73 carry forward unchanged.
