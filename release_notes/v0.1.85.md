# Notepatra v0.1.85

**Markdown Light theme palette overhaul, Claude-Code-blue text selection, neon-orange match highlight, and a real Scintilla byte-order bug fix.**

## What changed

The v0.1.84 Markdown Light palette landed but felt off — Solarized's full accent wheel was too "rainbow" for prose, and the yellow H2 had the classic low-contrast-on-pale-paper problem. After two iterations on the user's couch (Solarized → jewel-tone purple/magenta/blue → final SSMS), the Light theme Markdown palette is now reusing the same hues users already love from SQL files. While we were in the file, the text-selection background was also bumped to Claude Code's bright cyan-sky tone, and a real bug was uncovered: Scintilla's `SCI_INDICSETFORE` expects a Win32 COLORREF (BGR byte order), but `editor.cpp` was passing Qt's RGB — so the double-click word highlight had been rendering the wrong color all along.

## The fixes / additions

### 1. Markdown Light palette — SSMS-inspired six-hue spine

`src/npp_palette.cpp` now applies an SSMS-canonical palette to `Markdown` headings on Light theme (Dark + Monokai untouched):

| MD element  | Hex       | Mirrors SQL style                                |
|-------------|-----------|--------------------------------------------------|
| H1          | `#FF00FF` | SSMS keyword2 (system types like `INT`)          |
| H2          | `#0000FF` | SSMS keyword (`SELECT`, `FROM`, `WHERE`)         |
| H3          | `#7F0000` | SSMS classname / quoted identifier               |
| H4          | `#000080` | SSMS operator                                    |
| H5          | `#FF8000` | SSMS number                                      |
| H6          | `#008000` | SSMS comment                                     |
| body        | `#1f1f1f` | near-black readable                              |
| bold        | `#000000` | strongest contrast                               |
| > quote     | `#808080` italic — SSMS string gray              |
| inline code | `#1E293B` (Tailwind slate-800) on `#CBD5E1` (slate-300) — denser chip |
| link        | `#0000FF` underlined — SSMS keyword              |
| HR          | `#000080` bold — SSMS operator                   |

Opening a `.sql` file and an `.md` file side-by-side now reads as the same hue family — no more "MD is the sad one in the corner."

### 2. Light theme text selection — Claude Code prompt-blue

`src/themes.h` Light theme selection bumped from VS Code's pale `#ADD6FF` wash to `#5BC8FA` — the bright cyan-sky tone Claude Code's interactive prompts and rename inputs use. Vivid enough to feel like an actual selection without obscuring underlying text.

### 3. Double-click word highlight — neon orange + BGR byte-order bug FIX

`src/editor.cpp:664-679` now sets indicator 9 to a saturated `#FF5500` neon orange (alpha 160 fill / 255 outline) — pure-orange wash that pops on the page. **More importantly,** the prior code passed `QColor::rgb() & 0xFFFFFF` directly to `SCI_INDICSETFORE`, but Scintilla expects a Win32 COLORREF (`0x00BBGGRR`), not Qt's RGB packing. So `#E8A88F` (clay-orange RGB) was rendering as `#8FA8E8` (a light blue-purple, B and R bytes swapped). That bug has been present since the indicator-9 code was first added; this release fixes it.

| Source                              | Before v0.1.85                          | After v0.1.85                            | Reference                                  |
|-------------------------------------|-----------------------------------------|------------------------------------------|--------------------------------------------|
| MD H1 on Light                      | Solarized orange `#cb4b16`              | SSMS magenta `#FF00FF`                   | SQL Server Management Studio canonical     |
| MD H2 on Light                      | Solarized yellow `#b58900` (low contrast)| SSMS blue `#0000FF`                     | SSMS                                       |
| MD inline code chip                 | Red `#dc322f` on cream `#eee8d5`        | Slate-800 `#1E293B` on slate-300 `#CBD5E1`| Tailwind                                  |
| Light selection                     | VS Code Light+ `#ADD6FF` (pale wash)    | Claude Code prompt-blue `#5BC8FA`        | Claude Code TUI focus rings                |
| Double-click match indicator        | Wrong color (BGR bug — clay rendered as blue-purple) | Neon orange `#FF5500` (correct BGR) | Win32 COLORREF spec                       |
