# Notepatra v0.1.132

**macOS hotfix: the v0.1.131 DMGs did not start. This release packages the missing library and adds build checks so a broken app bundle cannot ship again.**

If you are on Linux or Windows, nothing changes for you: those builds are functionally identical to v0.1.131. Everything new in v0.1.131 (safer saves, the tighter AI SQL gate, the Preview pane fixes, Finder file opening) is in this release too, and macOS users get it for the first time.

## What went wrong

Both v0.1.131 macOS DMGs, standard and Full, exited at startup. The app bundle was missing `libbrotlicommon.1.dylib`. Qt's macOS platform plugin loads FreeType, FreeType loads `libbrotlidec`, and `libbrotlidec` needs `libbrotlicommon`, so the app could not open a window.

No source change caused it. A Homebrew library on the build machine gained the new dependency between the v0.1.130 and v0.1.131 builds, and the packaging step did not copy it. Nothing failed before release: the old packaging check only looked for absolute Homebrew paths, the CI smoke test ran `--version`, which never loads the platform plugin, and the tests ran the build tree, not the packaged app.

Reported by a tester on macOS 27 on Apple Silicon. Thank you.

## Also fixed on macOS

- WebP and TIFF images did not load: their libraries' own dependencies, such as `libsharpyuv`, were not bundled.
- The bundled `libssl` pointed at a build-machine path for `libcrypto` instead of the copy inside the app.

## New build gates

- **Every library the macOS app needs must be inside the bundle, or the build fails.** `scripts/macos-bundle-closure.sh` checks every binary in `Notepatra.app` for both DMGs, after signing and again on the copy that goes into the DMG.
- **The macOS build starts the packaged app** and fails if it cannot open (`scripts/macos-launch-smoke.sh`).
- `scripts/test-macos-bundle-closure.sh` tests the checker itself, including the exact v0.1.131 failure, and runs in `release-check.sh`.

## Files touched

```
.github/workflows/build.yml           closure check + launch smoke test in both macOS DMG steps
scripts/macos-bundle-closure.sh       new: bundle and verify every dependency of the .app
scripts/macos-launch-smoke.sh         new: start the packaged app on macOS
scripts/test-macos-bundle-closure.sh  new: Linux-runnable self-test of the checker
scripts/release-check.sh              runs the self-test
rust-core/Cargo.lock                  rustix 1.1.4 -> 1.1.6 (test-only dependency, RUSTSEC-2026-0486)
```

No application source changed. The `rustix` update affects only `rust-core`'s tests; it is not linked into any shipped binary.
