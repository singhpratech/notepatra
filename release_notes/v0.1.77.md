# Notepatra v0.1.77

**MSI hotfix — finishes the v0.1.74 work.**

## What changed

Windows users who installed BOTH `notepatra` and `notepatra-local-ai`
side-by-side were still seeing the Repair/Remove maintenance UI even
after the v0.1.74 Component-GUID fix. Root cause: the two MSIs wrote
to the **same HKCR registry tree**:

```
HKCR\Notepatra.Document                           (shared ProgId)
HKCR\.txt → Notepatra.Document                    (and 27 more extensions)
HKCR\*\shell\Edit with Notepatra                  (shared shell verb)
HKCR\Directory\shell\Open in Notepatra            (shared folder verb)
HKCR\Directory\Background\shell\Open in Notepatra (shared background verb)
```

Windows refused to refcount these across two distinct products
(different ProductCode / UpgradeCode) and surfaced the maintenance
prompt for whichever MSI was installed second.

## The fix

`installers/windows.wxs` now defines variant-scoped names:

```
Regular variant                Local AI variant
─────────────────              ─────────────────
Notepatra.Document             Notepatra.LocalAI.Document
NotepatraOpen verb             NotepatraLocalAIOpen verb
Edit with Notepatra            Edit with Notepatra Local AI
Open in Notepatra              Open in Notepatra Local AI
Open folder in Notepatra       Open folder in Notepatra Local AI
```

Both MSIs now write to **non-overlapping HKCR subtrees**. Install
either, both, in any order — no maintenance prompt.

## Recovery for users on v0.1.72 / v0.1.73 / v0.1.74 / v0.1.75 / v0.1.76

Legacy installs registered the shared keys with their (now-orphaned)
component GUIDs. To clean them up before installing v0.1.77:

```
msiexec /x {B7C8D9E0-1F2A-3B4C-5D6E-7F8A9B0C1D2E} /qb   :: removes Notepatra Local AI by UpgradeCode
msiexec /x {8D5E3C42-1F9A-4B7E-9D6C-1A2B3C4D5E6F} /qb   :: removes Notepatra by UpgradeCode
```

Then install `notepatra-0.1.77.msi` and (optionally)
`notepatra-local-ai-0.1.77.msi`. New installs land in clean
non-overlapping HKCR trees and upgrade cleanly forward from here.

## Verification

Built both MSIs locally, extracted Registry table — zero shared
HKCR keys between the two variants in v0.1.77 (v0.1.76 had 30+).
