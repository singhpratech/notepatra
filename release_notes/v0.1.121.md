# Notepatra v0.1.121

**MCP design hardening — 6 fixes found by live-driving all 48 verbs against a running v0.1.120 editor. The read-only Welcome tab (index 0) was a silent trap: `list_open_tabs` now reports an `editable` flag on every tab, and the read / insert / compare / save verbs gate on it with specific errors. `save_tab` gains an optional Save-As `path` so an AI can persist a `new_tab`'s content to disk (still Write-tier and approval-gated). A new `select_range` verb (48 → 49 tools; new tiers Read 24 / Act 14 / Write 11) makes `replace_selection` usable by an AI. `git_*` verbs fall back to the editor's startup working directory. Generic error messages are replaced with specific, actionable ones. And inline and exported charts now render on Qt 5.15's WebEngine, which had been silently breaking every chart. No verb shapes change beyond the two additions above; the approval gate is untouched.**

### Fixed — the Welcome tab (index 0) is no longer a silent trap

The Welcome tab is not an editable buffer, but nothing told an AI that — reads returned emptiness and writes appeared to succeed while doing nothing. `list_open_tabs` now reports an **`editable`** (bool) flag on every tab, and the read, insert, compare, and save verbs gate on it: a call against a non-editable tab returns a specific, actionable error instead of a silent no-op. An assistant can now see which tabs it may touch and pick a real one.

### Added — `save_tab` gains an optional `path` (Save-As)

An AI could create content with `new_tab` but had no way to persist it, because `save_tab` could only write a tab that already had a file on disk. `save_tab` now accepts an optional **`path`** argument (Save-As): the tab is written to that destination. It remains a **Write-tier, approval-gated** verb — the path is validated *before* the approval card is raised, and the destination path is shown on the card so you approve exactly where the file lands.

### Added — `select_range` makes `replace_selection` usable

`replace_selection` operates on the current selection, but an AI had no verb to *establish* a selection, so the write verb was effectively unreachable. The new **`select_range`** verb (Act tier) selects a range of text in a tab by line/column or character offset. Tool count goes **48 → 49**, and the three-tier totals are now **Read 24 / Act 14 / Write 11**. `select_range` is visible and non-destructive, so it needs no approval; the subsequent `replace_selection` still does.

### Fixed — `git_*` works when Notepatra was launched from inside a repo

The read-only Git verbs (`git_status`, `git_diff`, `git_log`, `git_show`, `git_branch`) previously required an open workspace folder and reported "not a git repository" otherwise. They now fall back to the editor's **startup working directory**, so Git works when Notepatra was launched from inside a repository even if no workspace folder is open.

### Fixed — specific, actionable error messages

Several verbs returned generic failures that gave an assistant nothing to act on. "could not insert", "could not open compare view", and "needs Save As" are replaced with messages that say what actually went wrong and what to do next — which pairs directly with the new `editable` flag so an AI can recover instead of retrying blindly.

### Fixed — charts render on Qt 5.15 WebEngine

On Qt 5.15, whose bundled WebEngine is built on Chromium ~87, the Vega rendering path was silently broken: `render_chart` returned `rendered: true` while drawing nothing, and `export_chart` surfaced an `e.isString` error. The root cause is that Chromium ~87 predates `Object.hasOwn` and `structuredClone`, both of which the Vega scripts rely on. The chart bundle now **polyfills `Object.hasOwn` and `structuredClone` before the Vega scripts load**, which fixes chart rendering on Qt 5.15 WebEngine. (Charts are a Full / WebEngine-edition feature.)

### Unchanged — the approval gate

Every write verb — including the new Save-As `save_tab` — still goes through the same in-editor **Approve / Deny card** (120-second auto-deny, one card at a time, FIFO, no headless bypass), and the gate lives in the editor process, not the sidecar. `select_range` is Act-tier and non-destructive.

### Compatibility

The only new verb shapes are the additive `select_range` and the optional `path` on `save_tab`; every other v0.1.120 verb behaves identically. The editor remains local-first with no telemetry.
