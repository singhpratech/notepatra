# Notepatra v0.1.90

**Chart UX revamp — Vega-Lite v5 path for every chart type in Full flavor, multi-metric overlay, dual-axis, universal facet, PNG/SVG/HTML/Spec export, offline (no JSDelivr in the loop), and a beefed-up Data Analyst playbook so the AI does real multi-step analysis.**

## The headline

v0.1.89 and earlier rendered chats via QtCharts. Three structural ceilings kept biting us in patch releases:

1. Labels truncated at slot-width regardless of rotation (v0.1.87 → v0.1.89).
2. No per-bar colour in `QBarSet` (worked around in v0.1.89 with the N-series hack).
3. No heatmap / density / regression-line / faceted small-multiples.

v0.1.90 routes the same Notepatra simplified chart spec through Vega-Lite v5 via QtWebEngine when the Full flavor is installed. Lite flavor keeps the QtCharts path for the chart types it can do, falls back to a "Install Charts Pack" stub for the five new types.

## New chart types

Five additions in the ```chart fenced block:

```
heatmap            x + y + value column → coloured-cell grid
density            x numeric column     → smoothed distribution
regression-line    x + y + method       → scatter w/ fitted line
faceted-bar        x + y + facet        → small-multiples bar
error-bar          x + y + yMin + yMax  → point + range
```

## Multi-metric overlay + dual axis

The simplified spec gained two optional knobs that work on `line`, `area`, `scatter`, `bar`:

- `"y": ["a", "b", "c"]` — overlay multiple series with one colour per metric, shared Y axis.
- `"y2": "secondary_col"` — dual-axis chart with two independent Y scales side-by-side (e.g. revenue in USD on the left, traffic count on the right).

## Universal facet — multi-dimensional questions in one chart

Add `"facet": "col"` or `"row": "a", "column": "b"` to **any** chart spec and Notepatra wraps it in a Vega-Lite facet structure. Combine with the overlay knobs to answer multi-dimensional questions in one go:

```chart
{
  "type": "bar",
  "x": "hcp",
  "y": ["calls", "sales"],
  "facet": "class",
  "data": [...]
}
```

→ "calls + sales per HCP, broken down by HCP class".

## Export menu

The chart-modal `Save as PNG…` button is replaced by `Export…` with four destinations:

| Format | Tooltips work? | Interactive (hover / zoom / pan / brush)? | Use case |
|---|---|---|---|
| **PNG** (1x / 2x / 4x) | no — static raster | no | Paste into Slack, screenshot in a doc |
| **SVG** | yes when opened in a browser | partial (hover yes; pan no) | Crisp vector for a report; scales infinitely |
| **HTML** (self-contained) | yes — full Vega | yes — everything | Email to a teammate; they explore it |
| **Spec JSON** | n/a | n/a | Paste into vega-editor.netlify.app to fork |

## Offline vega-embed bundle

vega + vega-lite + vega-embed (~828 KB total) are now shipped as a Qt resource (`resources/vega.qrc`) and loaded via `qrc:///vega/*.js`. The Full-flavor binary stays self-contained — air-gapped boxes render charts, CDN outages don't break anything. (Standalone HTML exports still link the CDN copies for portability.)

## DataAnalyst playbook — advanced multi-step analyses

The Data Analyst system prompt grew an `ANALYTICAL DEPTH` section that pushes the LLM toward real analyses, not single-query bail-outs:

1. **Discover** — `LIMIT 5` + count/distinct/min/max/avg sweep first.
2. **Aggregate** — GROUP BY the dimensions the user asked about.
3. **Decompose** — break the headline by a second dimension.
4. **Compare** — multiple periods, top-N + long-tail.
5. **Surface anomalies** — outliers (>3σ or top/bottom 1%), material nulls, low-cardinality red flags.

Plus a `SQL PATTERNS THAT EARN THEIR KEEP` cookbook (time bucketing, rolling windows, percent-of-total, YoY via LAG, cohort fixing via window-MIN, NTILE quartiles, percentile-fenced outlier filters) and a `MULTI-DIMENSIONAL QUESTIONS` section steering the model toward the y-array / y2 / facet combo for analyst-grade questions.

## Verification

- `ctest` 32/32 pass on Linux Full flavor.
- Binary size: Full flavor 37 MB (was ~36 MB; +1 MB from the qrc bundle).
- All five new chart types render without error in `test_chart_types`.
- Prompt size at 8 KB project context: ≈ 14.5 KB (under the 18 KB cap).

## Known limits

- Faceted charts with more than ~20 facet panels can get cramped at default 320 px height. Future polish: auto-bump height when facet cardinality > 6.
- Vega-Lite exports SVG with embedded `<title>` elements that browsers render as tooltips, but interactive zoom only works in the HTML export.
- The QtCharts fallback path (Lite flavor) ignores the new `facet`/`y2`/`y`-array knobs — Lite users get the single-metric chart.
