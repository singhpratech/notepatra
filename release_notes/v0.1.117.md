# Notepatra v0.1.117

**The honesty release. A 32-agent adversarial audit reviewed every component of the editor, every confirmed defect was fixed, ~4,100 lines of dead code were removed, and ~150 dormant Rust-core unit tests were promoted into CI and the release gates. No new dependencies, same bare binary (slightly smaller). Full offscreen ctest 70/70.**

### Fixed — Find & Replace tells the truth
- **Find in Files now shows its results.** Matches were being written into a widget that was never displayed — the feature ran the search and silently discarded everything. Results now stream into the persistent results panel, exactly like Find All.
- **"Match whole word" is honored everywhere** — Count, Replace All, Replace All in All Opened, and Find in Files previously ignored it.
- **Find All line numbers are correct in non-ASCII documents** (the position accumulator mixed byte and UTF-16 offsets).
- **Replace All with zero matches no longer marks the document modified.**
- The Replace tab's Find Next button now honors Extended (`\n`, `\t`) mode.
- Controls that did nothing — the Up/Down direction radios, both "In selection" checkboxes, and ". matches newline" — are hidden until they actually work, instead of silently lying.
- Double-clicking a search result from an unsaved tab no longer opens a bogus "Untitled" file.
- Mark is now reachable from the Search menu (previously the Mark tab had no menu entry or shortcut).

### Noter — export unlocked, pop-out polished
- **Notes can now be exported as PDF or Markdown** from the note's right-click menu. The exporter (557 lines) was fully implemented and unit-tested — it simply had no UI entry point.
- The pop-out window (Ctrl+Alt+P) is **resizable**, its always-on-top pin **shows its state**, its border/background actually paint, and long titles elide instead of clipping.
- Noter's dialogs (reminder picker, Extract review, confirmations) now follow the **Dark and Monokai themes** instead of flashing platform-default white.
- A slim edge button restores the sidebar after Ctrl+Alt+B hides it (previously there was no visible way back).
- The reminder banner stops strobing after a few flashes (it kept flashing at 600 ms until dismissed).
- Deleting a note permanently now shows the note's title instead of its raw internal `.trashed-…` filename.

### Fixed — editor & shell
- **UTF-32 files containing emoji / non-BMP characters no longer corrupt on save** — save and reload now use proper UCS-4 conversion, covered by a new byte-level round-trip regression test.
- The "Double-click to close tab" preference actually closes tabs now (it was a dead setting).
- Manual tab colors follow their tab through reorders and closes (they were keyed by index and drifted).
- The terminal gained a real **Stop** button (terminate, then kill), and the false "Ctrl+C in the editor stops the command" help text is gone. External-terminal handoff is now platform-guarded on Windows/macOS.
- Welcome's "Open folder…" gives visible feedback instead of silently doing nothing.
- Compare: the dead Stage/Revert buttons (which popped internal-jargon TODO dialogs) are hidden; the merge helper no longer orphans its window when a file has no conflicts.
- `.po` (gettext) files get comment/uncomment shortcuts and are auto-detected; the Python Save As filter no longer claims `.pyx`/`.pxd` (those belong to Cython).

### Improved — AI & charts
- **Image attachments are no longer blocked by a hardcoded vision-model list** — attachments are sent to whatever model you chose, and the backend's own error is surfaced if it can't handle them.
- The voice-input button only appears where it can work (Linux with `arecord` + `whisper` on PATH).
- The AI interaction log now uses the same ~20-pattern credential scrubber as the rest of the app (was a weaker 7-pattern copy).
- Bar charts with multi-series data render as grouped bars in the Lite build (previously errored; Full/Vega already auto-routed).
- The chart export dialog and the merge helper are readable in **Light, Dark, and Monokai** (both were single-theme).

### Leaner and better tested
- **~4,100 lines of dead code removed**: two abandoned pre-v0.1.95 Noter panel/menu modules, six unreachable embed renderers, a phantom root-level test file that never compiled, dead CMake blocks referencing deleted sources, and dead PDF-pack plumbing.
- **~150 Rust-core unit tests now run in CI** (`cargo test` in the quality workflow) **and gate every release** (release-check.sh) — they existed but never ran anywhere. Plus 7 new tests for the Rust search engine.
- The git-panel test was registered into ctest (it was tracked but never compiled) and a real bit-rot bug in it was fixed. Suite total stays 70/70.
- The UI smoke script derives its expected version from CMakeLists instead of a hardcoded stale string.

### For AI assistants & researchers
- New [`llms.txt`](https://notepatra.org/llms.txt) — a machine-readable project summary for AI assistants, with counts gated by the same script that keeps the website honest.
- `robots.txt` explicitly welcomes AI crawlers (GPTBot, ClaudeBot, PerplexityBot, and others).
- New `CITATION.cff` and `CODE_OF_CONDUCT.md`.
- Docs: new **Encodings** section (detection table, reload-vs-convert semantics, BOM round-trip guarantee), new **Font Pack** section, corrected Compare/Terminal/Search/autosave descriptions, and Noter export + pop-out documentation.

No new dependencies. The bare binary shrinks slightly from the dead-code removal.
