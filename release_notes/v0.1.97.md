# Notepatra v0.1.97 — Noter reminders: a central list, smarter Extract, cloud fixes

**Release date:** 2026-05-25

v0.1.95 redesigned Noter into a two-pane meeting workspace; v0.1.97 makes its **reminders** actually useful. Every reminder you set — on a note or pulled from an AI Extract — now lives in one **central Reminders list** in the sidebar, Extract resolves natural-language times like *"10am tomorrow"* into real reminders, and three crash/connectivity bugs in the cloud-AI path are fixed.

---

## Central Reminders list

A new **Reminders** root sits in the Noter sidebar between **Notes** and **Trash** (the note view itself is unchanged). It lists every scheduled reminder, grouped into collapsible **Overdue / Today / This week / Later** sections.

| Action | How |
|---|---|
| Open the note a reminder belongs to | click the reminder |
| Change its time | the row's **pencil** (calendar + time picker) |
| Delete it | the row's **✕** |
| See/manage everything in one place | the Reminders root — overdue items render in red |

Reminders come from two places, both shown here: right-click a note → **Set reminder…**, or schedule action items straight from **Extract**.

---

## Extract is smarter

Running **Extract** (footer button or `Ctrl+Alt+E`) over a note now:

1. **Schedules real reminders.** Previously the "Remind" checkboxes were cosmetic — Accept only appended text. Now each checked action becomes a reminder in the central list. Remind defaults **on only when a concrete time was extracted**, so tasks with no stated time don't auto-schedule a guessed one.
2. **Resolves natural-language times.** *"ship the build 10am tomorrow"* comes back with the date/time pre-filled at the right local wall-clock — no UTC drift.
3. **Writes a summary.** A short plain-English recap of the note (the model's understanding) shows at the top of the review dialog and is saved above the action items.
4. **Flags duplicates.** Re-running Extract lists what's already scheduled for the note and default-unchecks any action that matches — so you don't pile up duplicate reminders. It still categorizes into Action Items / Decisions / Questions / Risks.

## Cloud-AI fixes (OpenRouter / OpenAI-compatible backends)

| Symptom | Root cause | Fix |
|---|---|---|
| "OpenRouter API unreachable", empty model dropdown | endpoints built `…/api/v1/**v1**/models` (double `/v1`) → HTTP 404 | `openAiV1Base()` normalizes the stored base URL before appending |
| Chat / Extract **spins ~60s with no feedback** on a bad/expired key | a streaming 401 body isn't an SSE frame, so neither `finished` nor `error` fired | surface a prompt, actionable error (`Authentication failed (HTTP 401) — … paste a valid key`) from the finished handler |
| **Cancelling the Extract result crashed the app** (SIGSEGV) | the review dialog opened *inside* the network signal while the reply was still tearing down → a trailing `downloadProgress` hit freed memory | the dialog now opens on a clean event-loop tick after the client is fully severed |

## Documentation

Noter is now documented where you'd look for it: the in-app **Help → Notepatra Help Guide** has a Noter section (notes, Extract, the central Reminders list) and an **AI Interaction Log** note; the Welcome screen card text is current; and the website docs cover Noter + the interaction log.

The **AI Interaction Log** (Features → *AI Interaction Log…*) records every request/response to any AI backend — local or cloud, including Noter's Extract — for 7 days in a browsable, credential-scrubbed table. On by default; opt out in Settings → AI.
