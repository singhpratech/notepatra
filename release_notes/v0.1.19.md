# Notepatra v0.1.19 — Project Search hang fix · clean wordmark

**Released:** 2026-04-24

A follow-up to v0.1.18 focused on two user-reported problems:

1. **Project Search got stuck at some percentage on Windows** — traced to OneDrive placeholder files + runaway single-file reads on network drives / AV-locked files.
2. **"Notepatra — Native..." label rendered as "Notepatra(her) native..."** on older Windows installer views — the em-dash bytes were being interpreted as CP1252. Now the label is simply "Notepatra".

---

## Highlights

### 🔎 Project Search — Windows hang fixed

Three concrete defences land in v0.1.19 so one pathological file can no longer wedge the whole scan at *N %*:

- **OneDrive / cloud placeholder skip.** On Windows, the worker now calls `GetFileAttributesW()` on every candidate file and skips anything carrying `FILE_ATTRIBUTE_RECALL_ON_OPEN` / `_RECALL_ON_DATA_ACCESS` / `_OFFLINE`. Cloud-only placeholders no longer trigger a giant background WAN download when Search tries to open them — the #1 reason the bar used to freeze around 10–20 %.
- **Per-file 30-second watchdog.** Every file gets a `QElapsedTimer`; if the read loop has burned more than 30 seconds on a single file (antivirus RT-scan stalling, UNC share dropping, a 2 GB log with no newlines…), the worker bails on it and moves to the next file. One rogue file can't hold the scan hostage anymore.
- **Live "⏳ stalled on: <path>" diagnostic.** If the scan appears frozen for 2 seconds (20 consecutive UI ticks at 10 Hz), the status label appends the exact path of the file any worker thread is currently holding. You can see *which file* the scan is stuck on, so if the watchdog isn't the right fix for your environment you can exclude it via the glob input.
- **Progress ticker bumped from every-8-files to every-4-files.** Smoother bar motion, earlier detection of a stall.

### 🏷️ Clean "Notepatra" wordmark

No more dashes, em-dashes, or tagline clutter in OS-level labels.

- **Windows MSI** `Description` (shown in Settings → Installed apps): "Notepatra".
- **Windows NSIS** `BrandingText` (bottom of installer wizard): "Notepatra".
- **license.rtf** title (shown in installer license page): "Notepatra — …" → "Notepatra - …" → ASCII hyphen so CP1252-reading Windows never mojibakes it again.
- **Website footer**: "Notepatra" on one clean line.

### 🎨 SQL / C-family comment colour calibrated

Follow-up on the palette pass that landed earlier in v0.1.18:

- **Light theme** comment colour: `#008000` → `#0E8D0E`. More prominent green against Clay paper.
- **Dark theme** comment colour: `#6A9955` → `#A9B665`. Gruvbox-style olive that stays warm and distinct against `#1E1E1E` instead of blending with the accent teal.
- Monokai unchanged.

Applies to every QScintilla lexer (SQL `--` / `/* */`, C++ `//`, Python `#`, JS `//`, JSON-with-comments, Bash `#`) — anything the lexer's `description()` tags as a "comment" style.

## Installation

### Linux (AppImage)

```bash
wget https://github.com/singhpratech/notepatra/releases/download/v0.1.19/Notepatra-0.1.19-linux-x86_64.AppImage
chmod +x Notepatra-0.1.19-linux-x86_64.AppImage
./Notepatra-0.1.19-linux-x86_64.AppImage
```

### macOS

```bash
curl -fsSL https://github.com/singhpratech/notepatra/releases/download/v0.1.19/Notepatra-0.1.19.dmg -o ~/Downloads/Notepatra-0.1.19.dmg
open ~/Downloads/Notepatra-0.1.19.dmg
```

### Windows

- **MSI** — `Notepatra-0.1.19.msi`
- **NSIS installer** — `Notepatra-Setup-0.1.19.exe`
- **Portable ZIP** — `Notepatra-0.1.19-windows-x64.zip`

### One-command installer scripts

```bash
# Linux, macOS
curl -fsSL https://notepatra.org/install.sh | sh

# Windows PowerShell
irm https://notepatra.org/install.ps1 | iex
```

## Upgrade notes

- The in-app updater from v0.1.18 will pick this up automatically.
- No config, no scripts, no FFI changes — purely a hang-fix + cosmetic polish release.
- If Project Search still hangs on a specific file, watch the status label for `⏳ stalled on: <path>` and add a glob to the File types filter to exclude it. Please open an issue with the path so we can add a permanent skip rule.
