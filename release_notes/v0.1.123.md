# Notepatra v0.1.123

**The "Save As" dialog is now the native OS file dialog — the Windows Explorer tree everyone knows.**

## What changed

Save As was the *only* Notepatra file dialog that didn't look like the rest of your OS. Open, Open Folder, Save a Copy As, and the macro dialogs all use the **native** dialog already — on Windows, that's the familiar Explorer window with the folder tree in the sidebar. But **Save As** used Qt's own plain "Look in:" list, with no tree, which felt unfamiliar.

It now uses the **native OS dialog** — Windows Explorer (with the tree), the macOS save panel, and the native GTK/KDE chooser on Linux — so every file dialog in Notepatra matches what you're used to.

## Why it was non-native before (and how that's solved)

Back in v0.1.88.1, Save As was deliberately switched to Qt's own dialog because the native dialogs silently **drop the "which file type did you pick" signal** and return a stale value after you hit Save — so picking "JavaScript" from the dropdown and typing `foo` could save `foo.txt`.

v0.1.123 sidesteps that **without ever reading the dialog's filter**:

1. **`setDefaultSuffix` is driven by the current tab's language.** Native dialogs honour this — type a bare `foo` on a Python tab and it saves `foo.py`.
2. **A typed extension always wins.** If you type `foo.md`, it stays `foo.md` — the safety net only appends an extension when the path came back with none, so you can never get `foo.md.py`.
3. **On Windows**, the native dialog also appends the picked filter's extension itself, so changing the file type in the dropdown still works there.

The 72-language file-type dropdown is preserved on every platform.

| Dialog | Before v0.1.123 | After v0.1.123 |
|---|---|---|
| Save As | Qt's own "Look in:" list (no tree) | **Native** (Windows Explorer tree / macOS / Linux) |
| Open, Open Folder, Save a Copy As | Native already | Native (unchanged) |
| Bare name on a Python tab | `.py` | `.py` (unchanged) |
| Typed extension (`foo.md`) | honoured | honoured (unchanged) |

## Verification

GUI-verified in the running app on Linux: the native GTK chooser opens with the places sidebar and the "Python" filter preselected, and typing a bare name saved `renamed_by_test.py` on disk. The last-directory memory added in v0.1.122 continues to work through the native dialog.

## Out of scope

- The rich per-filter "change file type from the dropdown to change the extension" behaviour is best-effort on the native dialog (native Windows does it; some Linux themes only honour the default suffix). Type the extension explicitly if you want a type other than the tab's language.
