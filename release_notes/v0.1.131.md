# Notepatra v0.1.131

**Safer saves, a tighter AI SQL gate, a Preview pane that keeps its promises, and macOS that opens files from Finder.**

This release came out of a full audit of what v0.1.130 users hit first. Nothing here changes how a working setup behaves, except where the old behaviour could lose data or leak it.

## Your files

- **Saves never delete the old copy first.** Four places wrote a temp file, deleted the original, then renamed the temp into place. If the rename failed (an antivirus scanner holding the temp file is the classic cause), both copies were gone. They now replace the file in one step, and on failure the original is left untouched. Affected: Noter note saves, the AI's `apply_diff` edits to your source files, saved database connections, and AI chat history. The AI's edits also keep a script's executable bit.
- **Rename no longer overwrites another file.** Renaming a tab (tab menu or File › Rename) to the name of a file that already exists used to fail silently, then save your document over that other file. Rename now refuses an existing name, saves unsaved edits before renaming, and leaves everything as it was if any step fails.

## AI SQL gate

The Data analyst's `query_sql` and `csv_query` tools are read-only unless you approve a write on the card. An audit plus an independent review found ways around that, now closed:

- **No file reads from AI SQL.** On a DuckDB connection the assistant could run `read_text('~/.ssh/id_rsa')`, or `SELECT * FROM 'file.csv'`, and get the contents back. Unapproved AI queries now run with DuckDB's filesystem locked, and the classifier refuses file-reading functions and quoted strings used as tables. Saved CSV, Parquet, JSON and `.duckdb` connections still work. Remote `https://` and `s3://` connections keep network access but lose the local disk, and the lock cannot be undone from SQL. The error tells you to add a file as a connection instead.
- **SQL Server batches.** `SELECT 1 DROP TABLE users` has no semicolon, and SQL Server runs it as two statements. It counted as one harmless SELECT. On ODBC connections, a state-changing T-SQL verb anywhere in the query now needs approval.
- **Hidden statement separators.** A `;` could be hidden inside an escaped string (`E'x\''`, MySQL backslash escapes, `$tag$` strings), behind MySQL `#`, `--1` or `/*! */` comments, or after a carriage return that ends a `--` comment. The classifier now reads every query under each engine's rules and refuses it if any reading disagrees.
- **Read-only SQLite connections are opened read-only** by the driver, not just by the classifier.
- **"Approve all queries this turn" covers writes only.** Later reads still go through the read-only check.

The desktop SQL console and the Preview pane's SQL notebook are typed by you and stay unrestricted.

## Preview pane

- **Stop and the 120-second timeout work on every driver.** They used to flag a request only DuckDB listened to, so a runaway SQLite, PostgreSQL, MySQL or SQL Server cell stayed busy forever and could block quitting. Stop now frees the cell at once and discards the late result. The database may finish the query in the background.
- **The HTML preview loads nothing from the network.** v0.1.130 said it did not, but a test proved saved and untitled HTML tabs both connected out. The preview now has its own private profile that allows only local files and embedded data.
- **SQL results stay put.** Switching tabs and back, or editing a cell, no longer wipes results. An edited cell keeps its old table marked as stale.
- **The pane is remembered** across launches, open or closed, with its width.
- **`Ctrl+Shift+Return` runs the SQL cell and moves to the next one.** Both Run commands are in the View menu.
- **A `.sql` file without `-- %%` lines** runs the statement under the cursor on `Ctrl+Return`, instead of failing on the whole file.
- **Result tables:** `Ctrl+C` copies the selection as tab-separated text, and NULL shows the same dimmed way on every driver.
- **Save As, rename and language changes refresh the pane** without another keystroke.

## macOS

- **Opening files from Finder works.** Double-click, Open With and dropping on the Dock icon now open the file. Before, the app launched and opened nothing.
- **⌘Q quits.** The AI toggle had taken it; on macOS the AI panel is now ⇧⌘A. Replace moves off ⌘H (system Hide) to ⌥⌘F, full screen to ⌃⌘F, and the terminal to ⌃\`. Linux and Windows shortcuts are unchanged.
- **The DMG has an Applications link** to drag onto.
- **First-launch note.** The app is not notarized yet, so the download card and the MCP page now explain right-click › Open, and `xattr` for the MCP binary.

## Finding things

- The Welcome tab has cards for the Preview pane, Data analyst, Diagram and the MCP sidecar, and its icons no longer use emoji.
- The Feature Guide covers those four tools.
- Help has **Documentation** and **Show Welcome Tab**.
- Shortcut hints are fixed: Line Comment showed Ctrl+Q, and the AI shortcut was listed three different ways.

## Corrections to the v0.1.130 notes

- "No remote resources load" in the HTML preview was not true until this release.
- A cell with several statements did not run the first one; the Qt SQLite driver refuses it with "Unable to execute multiple statements at a time". That is still the case.
- Stop and the 120-second ceiling only worked for DuckDB until this release.
- Any `.sql` tab shows as a notebook, not only files with `-- %%` lines.

## Limits

- A stopped SQLite query keeps one CPU core busy until it ends or you quit.
- Cells with several statements are still refused by the Qt SQLite driver.
- The macOS changes compile and pass tests in CI, but were not tried on a physical Mac before release.
- The macOS app is still not notarized.

## Tests

New suites: `test_atomic_write`, `test_rename_tab_file`, `test_file_open_event`, `test_shortcuts_discoverability` and `test_preview_persist`. The SQL gate, AI write gate and Preview pane suites gained cases for every fix. Each new test was first run against the old code and failed there.

The registered suite count is now **86 on the Full build and 83 on Lite** (was 81 and 78).

## Verifying this release

Same as previous releases: SHA-256 in `SHA256SUMS`, cosign keyless signatures, SLSA build provenance. See `SECURITY.md`.
