# Notepatra v0.1.22 — Windows truncation pass (close-icon mojibake, button widths, header heights, status wrap)

**Released:** 2026-04-25

A second pass at Windows UI polish. v0.1.21 fixed widget-spacing collisions on Windows; this release fixes the **truncation** bugs the user found and screenshotted afterward.

Five concrete crops were visible in the screenshots:

1. AI dock close button rendered as `âœ•` mojibake (UTF-8 of `✕` decoded as CP1252).
2. Tool-panel top-line headers (SQL Formatter, Terminal, Function List, SOURCE CONTROL, JSON/HTML/Bracket title, Markdown Preview, Search Results, Compare left/right) clipping against the row below.
3. Find/Replace buttons truncated: "Find All in Current Document" → "Find All in Current"; "Find All in All Opened Documents" → "nd All in All Opene".
4. "Copy Output" button on JSON / HTML / Bracket / SQL Formatter clipping the right edge ("Copv Outout").
5. AI panel error messages like "Error transferring https://api.openai.com/..." wrapping off the right edge.
6. SQL Formatter Model dropdown showing "ot connected" instead of "(not connected)".

All six fixed.

---

## Highlights

### 🪟 Windows truncation pass — five concrete crops fixed from user screenshots

- **AI dock close button no longer renders as `âœ•` mojibake on Windows.** The previous Unicode glyph (`U+2715`) wasn't in every Windows font's coverage. Switched to `QStyle::SP_TitleBarCloseButton` — the OS draws its own X icon, guaranteed to render. Same fix for the Compare ✕ Close button.
- **Tool-panel top-line headers no longer clip on Windows.** Every tool-panel header (`SQL Formatter`, `Terminal`, `Function List`, `SOURCE CONTROL`, JSON/HTML/Bracket title, `Markdown Preview`, `Search Results`, Compare's left/right file headers) was `setFixedHeight(20-24)` which on Windows' larger font metrics + bold ascenders/descenders left the text overlapping with the row below. Switched to `setMinimumHeight(26-28)` with 4 px padding.
- **Find/Replace buttons no longer truncate on Windows.** `setFixedWidth(170/200)` was tight; switched to `setMinimumWidth(210/230)` and bumped the dialog floor 580→660 px.
- **JSON / HTML / Bracket / SQL Formatter "Copy Output" no longer clips at the right edge.** Right `contentsMargin` on the button row bumped 8→16 px.
- **AI panel error messages no longer truncate at the right edge.** `m_statusLabel` was `setFixedHeight(14)` with no word wrap. Switched to `setWordWrap(true)` + `setMinimumHeight(18)` + `MinimumExpanding` vertical sizePolicy so multi-line errors render in full.
- **SQL Formatter Model dropdown no longer shows "ot connected" instead of "(not connected)".** Combo `setMinimumWidth(150)` was tight; bumped to 200 + `setSizeAdjustPolicy(AdjustToContents)` so it also grows for long model names.

## Installation

### Linux (AppImage)

```bash
wget https://github.com/singhpratech/notepatra/releases/download/v0.1.22/Notepatra-0.1.22-linux-x86_64.AppImage
chmod +x Notepatra-0.1.22-linux-x86_64.AppImage
./Notepatra-0.1.22-linux-x86_64.AppImage
```

### macOS

```bash
curl -fsSL https://github.com/singhpratech/notepatra/releases/download/v0.1.22/Notepatra-0.1.22.dmg -o ~/Downloads/Notepatra-0.1.22.dmg
open ~/Downloads/Notepatra-0.1.22.dmg
```

### Windows

- **MSI** — `Notepatra-0.1.22.msi`
- **NSIS installer** — `Notepatra-Setup-0.1.22.exe`
- **Portable ZIP** — `Notepatra-0.1.22-windows-x64.zip`


- Windows user perspective: every panel's headers, button rows, and the AI / SQL status displays now read in full instead of cropping at the right edge.
