## Why this matters

Each topic is a clickable filter on GitHub. Once you add `code-editor`, anyone who clicks https://github.com/topics/code-editor sees you in the list. Topics also feed into:
- GitHub Trending (sortable by topic)
- The `gh search repos` CLI command
- Third-party services like libraries.io, openlogic.com, sourcegraph
- Google's site search of github.com

A repo with no topics is invisible to topic-based discovery. A repo with the right 20 topics is in 20 different funnels.

## After you save

GitHub will:
1. Display the description below the project name on the repo page
2. Show the website link as a clickable URL in the sidebar
3. Add the repo to each of the 20 topic pages within ~1 hour
4. Surface the repo in topic-filtered searches immediately
