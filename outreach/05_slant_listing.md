## Step 4 — add pros and cons

Slant uses pro/con voting. Add these (one at a time, you can paste them all in):

### Pros
- Native C++/Rust binary, only ~3-5 MB
- Cross-platform: Linux, macOS Apple Silicon, Windows
- Local AI via Ollama (no cloud, no telemetry)
- Plugin system for native shared libraries
- Built-in JSON / HTML / SQL / Bracket fixers
- Memory-mapped 2 GB file support
- Side-by-side file comparison with Myers diff
- Built-in Git integration with gutter markers
- Free forever, GPL-3.0
- Zero telemetry, zero analytics
- SHA-256 + cosign + SLSA build provenance for every release

### Cons
- Pre-1.0, expect rough edges
- No LSP support yet (planned for v0.2)
- Single maintainer (no SLA)
- Plugin ecosystem is brand new
- Notarization on macOS not yet enabled (Gatekeeper warns first launch)
- Authenticode on Windows not yet enabled (SmartScreen warns first ~20 downloads)
