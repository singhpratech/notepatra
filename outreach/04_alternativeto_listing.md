### Description (paste this — alternativeto.net allows ~1000 chars)

```
Notepatra is a native C++/Rust code editor inspired by Notepad++ but rebuilt for the AI era. It runs on Linux, macOS Apple Silicon, and Windows from a single codebase, with a tiny 3–5 MB executable (the actual binary, not a 300 MB Electron container).

It uses QScintilla — the same Scintilla editing engine as Notepad++ — and adds local AI integration via Ollama. The AI runs entirely on your machine; nothing ever leaves your computer.

Highlights:
• 100+ file types with 44 language lexers
• AI-powered JSON / HTML / SQL / Bracket fixers
• Memory-mapped 2 GB file support via Rust
• Side-by-side file comparison with Myers diff
• Built-in Git integration with gutter markers
• Macro recording and playback
• Session persistence and crash recovery
• Plugin system (.so / .dylib / .dll)
• Zero telemetry, zero analytics, zero phone-home
• Free forever, GPL-3.0

Notepatra is what Notepad++ would look like if Don Ho had built it in 2026 with Rust safety, cross-platform support, and AI as a first-class feature.
```

## After submitting

- alternativeto.net moderators review new listings within 24–72 hours
- Once approved, the listing goes live and counts as a permanent backlink
- Vote on your own listing (you get one vote)
- Ask 2–3 friends to upvote it as well — getting to 5–10 votes early bumps you out of the "0 votes" pile
- Don't ask for more votes than that — alternativeto.net detects vote stuffing
- Wait for organic discovery to take over

## SEO impact (realistic — not promises)

Once you have a handful of organic votes:
- You appear on https://alternativeto.net/software/notepad-plus-plus/ (the Notepad++ alternatives page), which is a well-trafficked editor-discovery destination
- Your listing has a chance to rank in Google for queries like "notepad++ for linux" and "notepad++ alternative mac"
- The backlink itself feeds Google's PageRank signal, contributing to your overall search position

This is generally regarded as the highest-ROI single action you can take for a new code editor — but **none of this is guaranteed**, and no single channel is going to flip the needle by itself. Do the listing and don't worry about the rest until traffic actually starts.
