# Notepatra Roadmap

## v0.1.0 — Foundation (CURRENT)
- [x] Core editor (QScintilla/Scintilla engine)
- [x] 60+ file types with syntax highlighting
- [x] Rust-powered core (mmap I/O, Aho-Corasick search, Myers diff)
- [x] 12 menus matching Notepad++ layout
- [x] Advanced Find/Replace (regex, extended, all opened docs)
- [x] File Compare (side-by-side diff)
- [x] SQL Formatter
- [x] Plugin system (.so shared libraries)
- [x] Double-click word highlight
- [x] Handles files up to 2.5 GB
- [x] 6-section status bar
- [x] File explorer, Function list panels
- [x] Bookmarks, code folding, auto-complete
- [x] Tools: Hash, Base64, URL encode/decode
- [x] Custom scrollbars, pastel green current line

## v0.2.0 — Developer Experience
- [ ] Built-in terminal (split pane below editor)
- [ ] Markdown live preview (split pane right)
- [ ] Git integration (changed lines in margin)
- [ ] Hex editor mode (binary file viewer)

## v0.3.0 — AI Era
- [ ] Ollama integration (local AI assistant)
- [ ] AI autocomplete (code suggestions)
- [ ] Prompt workbench (.prompt files)
- [ ] AI text transforms (right-click menu)
- [ ] Natural language to Regex/SQL

## v1.0.0 — Connected (Production)
- [ ] Remote file editing (SSH/SFTP)
- [ ] Live collaboration (share session link)
- [ ] Visual regex builder
- [ ] .http REST client
- [ ] Code screenshots (export as image)
