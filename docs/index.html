Features
Everything you need. Nothing you don't.
Built on QScintilla — the same engine that powers Notepad++. With a Rust core for memory safety and zero crashes.
🤖

AI Assistant (Ctrl+Shift+A) NEW

Local-first AI. Pick your runner: Ollama, llama.cpp (any GGUF), LM Studio, Jan, vLLM, or anything that speaks OpenAI's /v1/chat/completions. Explain · Find Bugs · Refactor · Write Tests · Fix JSON · Add Comments · Optimize · Translate. No cloud, no mandatory API key, no telemetry. Your code never leaves your machine.

🔎

Project Search (Ctrl+Shift+G) NEW

Lightning-fast recursive search across file names AND file contents, project-wide. No size limit — streams line by line so a 2 GB log searches the same as a 2 KB script. Exact line:col coordinates, double-click a match to jump the caret to the exact character. Any text-based language. Skips binary files with a NUL-byte heuristic.

⚡

Rust-Powered Core

Memory-mapped file I/O. Aho-Corasick search. Myers diff. Zero crashes on 2 GB files. The heavy lifting runs in compiled Rust — no garbage collector, no runtime.

🔄

Safe auto-update NEW

Notepad++-style update flow: click Download in the in-app "update available" dialog and the right artifact for your OS + architecture is fetched, SHA-256 verified against the release's SHA256SUMS, and handed to the native installer (MSI on Windows, DMG in Finder on macOS, file manager on Linux). Your current install is never touched by the updater — the OS installer does the swap under its own transactional rollback. Checksum mismatch, cancelled download, network drop, disk full — any failure leaves the running app exactly as it was.

📅

Insert Date / Time

Edit → Insert, or Ctrl+F5. Five formats: 2026-04-20 13:45, 2026-04-20, April 20, 2026, 13:45:09, ISO-8601. Saves keystrokes in logs, changelogs, meeting notes.

🖱

Clickable status bar

Click Language, Encoding, or EOL indicators in the status bar to pop the matching change-menu right where you clicked. Same UX as VS Code, Sublime, Atom.

📂

Clean menu organization

Three clear menus — Tools (everything built-in: AI, Terminal, Compare, JSON/HTML/SQL, Git, REST, Bracket), Plugins (third-party extensions YOU add), Utilities (Hash, Measurement). No more guessing where a feature lives.

🔀

Compare with word-level diff

Side-by-side Scintilla diff. Green for added, red for deleted, amber for changed — with LCS-based word-level intra-line highlighting so you see the exact tokens that changed. Dark mode aware. Prev/Next navigation. Ignore whitespace, case, empty lines.

📁

Session Persistence

Close Notepatra, reopen tomorrow — same files, same cursors, same window size. Crash recovery saves unsaved work every 10 seconds.

👁

File Change Detection

Someone edits your file externally? Notepatra asks: reload or keep yours. Git gutter shows changed lines in green/yellow/red.

🎙

Macro Recording

Record keystrokes (Ctrl+Shift+R), playback (Ctrl+Shift+P), run multiple times, save to .macro files, replay tomorrow.

📑

100+ File Types

44 language lexers — Python, Rust, Go, C/C++, Java, JS/TS, SQL, HTML, CSS, JSON, YAML, Markdown, Bash, Fortran, Verilog, MATLAB, LaTeX and more.

🎨

3 Themes + Color Tags

Light, Dark, Monokai. Color-tag any tab (7 colors + custom). Pastel green current line, double-click word highlight in orange.

🧩

Plugin System

Drop a .so/.dll/.dylib in the plugins folder. Simple C API — export 2 functions to create a plugin. JSON, HTML, SQL, Bracket tools all built in.

Security
Verifiable. Local. Hands off your data.
Notepatra never touches the network unless you tell it to. Every release is checksummed and cryptographically signed. Verify before you run.
🔐

SHA-256 checksums

Every release ships a SHA256SUMS file. install.sh and install.ps1 verify it automatically and refuse to install on mismatch. Latest checksums →

✍️

Cosign signatures (Sigstore)

Every artifact is signed via keyless OIDC signing tied to the official GitHub Actions workflow. The cert is recorded in the public Rekor transparency log — no trust in any single key.

📜

SLSA build provenance

Every binary carries a cryptographic attestation linking it to the exact git commit + workflow file + runner environment that built it. Verify with gh attestation verify.

🦀

Rust safety + cargo audit

All untrusted-input code paths (file load, search, parsers) live in Rust. CI runs cargo audit on every build to flag vulnerable dependencies.

🚫

Zero telemetry

No analytics, no error reporting, no phone-home. The only outbound connections are: localhost Ollama (when you use AI), git push/pull (when you click), and HTTP requests you explicitly send via the REST tab. Verifiable with strace.

📬

Responsible disclosure

Found a vulnerability? Use private vulnerability reporting. Full policy in SECURITY.md and /.well-known/security.txt.

v0.1.17 LATEST
2026-04-24 · Safe in-app updater + Project Search rewrite (honest progress, live counters, page-scroll, fix never-fired worker) · Linux · macOS · Windows
🔄 Safe in-app updater — Notepad++-style
  • "Update Available" → Download → done. Picks the right artifact for your OS + arch, stream-downloads with a progress dialog, fetches SHA256SUMS and verifies, atomic-renames, hands off to the native installer (msiexec /i on Windows, Finder drag-to-Applications on macOS, opens the Downloads folder on Linux).
  • Running Notepatra is NEVER touched by the updater. Only the OS installer you click through may replace it, and MSI/Finder/file-manager all have their own rollback. Checksum mismatch, cancel, network drop, disk full — any failure deletes the .part file and leaves your current install 100 % intact.
  • 18-case deep test (test_updater.cpp) on the two pure safety-critical functions — asset picker and SHA256SUMS parser.
🔎 Project Search — fixed, honest, streaming, page-scrollable
  • Critical bug fix. QMetaObject::invokeMethod(m_worker, "search", Q_ARG(ProjectSearchWorker::Params, p)) was silently failing — the type-name string didn't match the slot's unqualified "Params". The worker was never called. Switched to the lambda overload. Every search from the UI now actually runs.
  • Honest 0 → 100 % progress bar — no bouncing, no fake walk share. Fills linearly from scanned / total.
  • Full live status line: Searching — 48 / 212 files (22%) · 28,340 lines · 3 matches · 180 ms elapsed. A 10 Hz UI timer refreshes elapsed-ms between worker events so it visibly scrolls.
  • Page-level scroll — the whole tab lives in a QScrollArea, the match tree grows to fit content, the page scrollbar takes over. One scroll, not two. Matches VS Code / Cursor / Sublime.
  • Right-click context menu on a match: Copy location (path:line:col), Copy full path, Copy match line text. Parent rows show full absolute paths, copyable.
  • Instant Cancel — immediate "Cancelling…" feedback, worker bails at next m_cancel.load(), post-cancel events ignored via phase guard.
  • Ctrl+Shift+F (Find in Files) wired correctly — menu said "Find in Files…" but action called showFind() (tab 0) instead of showFindInFiles() (tab 2). One-char bug, a month silent.
  • 27-case worker deep test + new 5-case headless UI test proving status-line transitions end to end.
🧩 Help menu + 🎨 Website timeline
  • Help menu now has direct links: Notepatra on GitHub, Latest Release, Report an Issue — each opens the correct GitHub page in your browser.
  • Website Version History collapses every non-latest release into a single clickable row, with a vertical timeline rail + colored dot per release. Keyboard accessible (Enter / Space).
🧹 CI + tests
  • Removed the dead daily docs/stats.json pipeline — it was red for weeks (E2BIG / branch-protection). The website's download counter reads directly from the GitHub API at page-load; nothing consumed stats.json anyway.
  • Full ctest -j: 11/11 pass including test_projectsearch (27), test_updater (18), test_projectsearch_ui (5).

  • Dir walk pruning. Skips .git, node_modules, target, build, dist, __pycache__, .venv, .next, vendor, DerivedData, and 15 other heavy dirs up-front. On this repo: 3,512 files walked → 212. Matches ripgrep's default skip list.
  • Rust aho-corasick is finally wired in. Literal searches on files ≤ 8 MB go through RustCore::findAll() — the same aho-corasick crate ripgrep uses — mapping byte-offsets to (line, col) via upper_bound over a pre-built line-start index. Regex searches and files > 8 MB still stream line-by-line so 2 GB logs stay RAM-safe.
  • Parallel file scanning via QtConcurrent::blockingMap. Uses every CPU core; roughly 3–4× faster than the serial version on a 4-core laptop.
🖥️ Terminal — interactive CLIs work in-line
  • claude, codex, aider, gh, python / ipython, node, ssh, mosh, psql, mysql, sqlite3, gdb, lldb now get a real TTY via script(1) wrapping and run inside the Notepatra terminal. Input box flips to stdin-feed mode; prompt changes to <cmd> ▷.

  • Alignment fixes for streamed output: replaced QTextEdit::append() with cursor-positioned insertHtml + <br>. Bare cd now means $HOME.
🧪 CI back to green · 🎨 Welcome logo · 🖼 Real tour GIF
  • test_llamacpp and test_ai_context were registered with CTest but missing from the explicit cmake --build --target list — every push landed red. Fixed. Linux + Linux-ARM regression suites pass again. New test_ai_context unit test — 21 assertions on the workspace-context block builder, runs headless.

FAQ
Frequently asked questions
Quick answers. For deeper docs see the README and SECURITY.md.

How is Notepatra different from Notepad++ or VS Code?

Notepatra is its own native code editor — written from scratch in C++ and Rust, not a port or a clone. Runs on Linux, macOS Apple Silicon, and Windows from one codebase. Compared to Notepad++: truly cross-platform, local-first AI is built in, Rust-powered search and formatters. Compared to VS Code: 6–14× smaller, zero Electron, zero telemetry, instant startup, no account required. Credit to Don Ho for proving a code editor can be small, fast, and free.

Is it really free? What's the catch?

No catch. GPL-3.0, no telemetry, no analytics, no API key, no enterprise tier, no subscription. Source on GitHub. The "catch" is that it's a one-person open-source project — no SLA, no warranty, no support contract. See the disclaimer in the footer.

How big is it compared to VS Code?

The bare executable is ~4 MB stripped across every platform. Actual downloads (v0.1.17): 2 MB Linux tar.gz · 22 MB macOS DMG · 40 MB Windows MSI/zip. Linux is small because Qt is a system package; macOS and Windows bundle Qt + QScintilla DLLs for portability. VS Code is 300+ MB regardless. Notepatra stays 6× to 14× smaller in every configuration.

Does my code go to the cloud?

No. Notepatra is local-first. The AI runs on your machine via Ollama (which you install separately). The only outbound connections are: localhost Ollama, git push/pull when you click them, and the REST client when you send a request. Verifiable with strace.

What languages does it highlight?

100+ file types via 44 language lexers — Python, JavaScript, TypeScript, C, C++, C#, Java, Rust, Go, HTML, CSS, SQL (T-SQL/PL/SQL/MySQL/PostgreSQL/SQLite), JSON, YAML, Markdown, Bash, Ruby, Perl, Lua, Fortran, Verilog, VHDL, MATLAB, LaTeX, Pascal, CMake, Makefile, and more.

How do I verify a download is genuine?

Every release ships with SHA-256 checksums, cosign signatures (Sigstore + Rekor), and SLSA build provenance. The install scripts verify SHA-256 automatically and refuse to install on mismatch. Full guide in SECURITY.md.

Will it open big files?

Yes — up to 2 GB. The Rust core uses memory-mapped I/O (mmap2), so opening a 2 GB log file is instant and doesn't allocate 2 GB of RAM. Files larger than 50 MB automatically disable syntax highlighting and auto-complete to keep things snappy.

Can I write plugins?

Yes. Drop a .so/.dylib/.dll in ~/.config/notepatra/plugins/. The plugin C API is two functions: notepatra_plugin_name() and notepatra_plugin_run(text, len). Example in the README.

Who built it and why?

Built by Prateek Singh, constructed with Claude. The short version: Linux and macOS deserved a first-class native code editor, and 2026 deserved one with AI built in. Respect to Don Ho for showing — 15+ years ago, with Notepad++ — that a code editor can be small, fast, and free.

The Story

I'm Prateek Singh. A developer who spent years on Linux watching Windows users open Notepad++ and fix things in seconds — broken JSON, messy SQL, tangled HTML — while I was stuck with Wine hacks or bloated Electron editors eating 500 MB of RAM to show a text file.

Every text editor told me to pick two: fast, powerful, or native. Vim is fast but cryptic. VS Code is powerful but heavy. Notepad++ is both — but it only runs on Windows.

So I built Notepatra. Not a port. Not a wrapper. Something new — for everyone. I asked: what would Notepad++ look like if it was built today, in 2026, when AI is part of every developer's workflow?

The answer: a tiny native binary (~4 MB bare, ~2 MB compressed) with a Rust-powered core, Scintilla editing engine, and local AI integration. No cloud. No telemetry. No subscription. Just you and your code — on Linux, Windows, and macOS.

Ready to try?

One command. No installer. No bloat. Just an editor that works.
