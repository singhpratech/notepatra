Meeting Thinkpad · UX Design Review · v0.1 · 2026-05-21

The meeting note wired to your work.

A keyboard-driven thinkpad embedded in Notepatra. Type freely during a meeting, paste images, link pull requests, reference code by file:line. One button at the end extracts decisions and action items, and your laptop nags you about your commitments at their due time. Local-first, HTML on disk, zero voice capture, no bots.

Storage · HTML Sync · None — filesystem AI · Reuses Notepatra panel Voice · Permanently dropped Scope · Notes tab only · no Notepatra UX changes

Plain paragraphs have zero chrome. 95 % of content stays out of the way.
02

03

04

05

06

SURFACE 11

Discoverability — no manual required

Six channels

A user opens the Notes tab for the first time. They don't read docs. Here's how every feature surfaces itself, in priority order from "absolutely-can't-miss" to "graduates to keyboard."

channel 01 · empty state
The keystroke hint, dead-center.

The empty canvas tells you exactly what to do — one shortcut, four recent files. If you don't know what Ctrl+Alt+N does, just click a recent note. Zero ambiguity.

channel 02 · edge icon strip
Hover any icon · see name + shortcut.

Four icons on the left edge (📂 📋 ⏰ ≡). Hovering shows the name and shortcut. Clicking opens that panel. No menu diving required.

channel 03 · right-click
Every action, where you point.

Right-click any block, any selection, any note in the sidebar — the menu shows exactly what's possible from that context, with shortcuts on the right edge so you learn the keys naturally over time.

channel 04 · slash menu
Type / · the catalog opens.

All six block types + six embed types appear in a single popover. Number keys insert. Esc cancels. Discovering the slash menu means discovering every special block in the app.

channel 05 · block hover (⋯)
Mouse over · three-dot menu.

Hovering any block reveals a ⋯ button. Click → same menu as right-click. For users who don't know right-click exists (or prefer left-click flows). Discovery without forcing keyboard fluency.

channel 06 · inline placeholder
Empty line · faint cursor hint.

First empty line on a new note: "Begin typing. / for blocks, @ for people, :d for a decision." Disappears the moment you type.

SURFACE 13

Engineering · HTML storage + reliability

Twelve defenses

Notes are HTML files in ~/Documents/Notepatra/Notes/<notebook>/<section>/<note>.html. SQLite is a rebuildable cache. Twelve specific failure modes, twelve defenses. Plus PDF and Markdown export — both one-click, both lossless for the typical case.

01 · power loss mid-write
Atomic write

note.tmp → rename. POSIX-atomic.

02 · crash mid-edit
Draft sidecar

5-sec dump to .draft. Offer to recover on launch.

03 · two windows open same note
Lock file

.lock with PID. Second opener: read-only prompt.

04 · invalid HTML paste
Sanitizer

Whitelist of tags + attrs. No script, no onclick, no inline style.

05 · schema drift
Schema header

<meta name="notepatra-schema" content="1"> in every file.

06 · save corrupts file
Validate-before-write

Parse + balance check. Block save on invalid. Never silently corrupt.

07 · external hand-edit broke it
Repair mode

Parse fail → raw-text editor with banner. Never crash, never lose bytes.

08 · 50 MB image pasted
Embed caps

Refuse paste > 20 MB. Downscale > 4096 px → WebP 85 %.

09 · filename special chars
Sanitize

Strip < > : " / \ | ? * \0. Date-prefix + 200-char cap.

10 · rsync / Syncthing conflict
Conflict copy

No on-disk locks. Sync tools write note (conflict).html. User merges manually.

11 · SQLite cache corrupt
Rebuild from HTML

Files are authoritative. Cache is derived. One-click rebuild.

12 · "I want my old save back"
Backup ring

Last 5 saves rotate as .bak1 … .bak5. Disk is cheap.

conversion paths · all one-click
HTML → PDF  ·  Browser print engine via QWebEngineView headless. v1 · ~10 LOC · zero new deps.
HTML → Markdown  ·  Bundled turndown.js or Rust html2md. Embeds become ![](assets/img-N.png) + sidecar folder.
Markdown → HTML  ·  pulldown-cmark on import. Drag-drop existing Obsidian / Bear notes into Notepatra.
HTML → plain text  ·  Trivial DOM strip. Useful for piping into another tool.
HTML → email body  ·  Copy → paste into Gmail / Outlook keeps every embed.
HTML → DOCX  ·  pandoc (optional download). Not v1.
